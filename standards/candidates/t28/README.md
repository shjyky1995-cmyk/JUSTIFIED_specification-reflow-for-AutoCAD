# T28 表格候选标准

这是待 CAD 实测的试用资产，不覆盖 `standards/published` 的已发布版本。

- 说明标准 jsr-note 1.1.0：原有文字参数不变。表内左右留白各 0.25 倍字高，上下各 0.15 倍字高；表前后额外空行 0；实线 Continuous，线宽 0.18 mm，图层 JSR_NOTE_TABLE。
- 参数是本项目按已确认方案制定的规则，尚无真实字体/打印验收证据。留白与行高由测量共同决定，行高始终为正文行距整数倍。
- 自动列宽仅适用于源文档明确 `tcW=auto`、没有网格和合并的矩形表；由配置 `equal-columns-with-warning` 允许等宽，并发出 W_TABLE_AUTO_WIDTH。改为 `reject` 可要求所有表明确列宽。缺列宽且不满足此条件仍阻断。
- 图幅模板 1.2.1 修复 1.2.0 继承的下边距错误。原模板将说明区向下移动 60 mm 时也移动了底边，侵占原定图签留白。保留栏左右位置、顶部 -60、首基线 -66.2、行距 7.2；恢复距纸底 A1 41.63 / A2 50 / A3 52 mm 的安全区，每栏调整为 68 / 43 / 25 槽。文字字形和表格完整边线都受同一栏边界约束，不能靠缩小字体增加容量。
- 旧 1.2.0 模板保存在 `standards/candidates/t28-preview1` 供历史复现，不进入新版安装包，避免同图幅多模板冲突。`calibrated` 是既有加载分类；真实 DSS/工程图框验收仍 pending。
- 文件内 `production` 是既有加载器的业务标准分类，不是发行签收。候选包 BUILD.json 明示 `productionReady=false` 与人工待验项；每种图幅仍只打包一份模板。
