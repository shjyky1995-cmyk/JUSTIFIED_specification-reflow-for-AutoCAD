# 可编辑规则草案

本目录是设计输入，不是已验收生产包，也不是供运行时直接加载的目录。字体格式与图幅模板分别版本化，入口见 docs/TEXT_FORMAT_V1.md 和 docs/PAPER_TEMPLATES_V1.md。尚未发布的本次草案随用户反馈更新，发布后禁止原地覆盖。

classification=draft 必须被正式读取器拒绝。标准中的 pending/null 明示尚未验证或尚未实现的符号映射、换行版本、公差，不能替换为任意测试值。模板仍 uncalibrated；完成真实验证后按正式目录结构打包，而不是简单移动文件或只改状态。

现有契约已支持可调字高、宽度、行距、缩进、栏数组、首基线、行数、页步长与精确版本引用。两个半角空格的内联编号策略按当前文字规则实现；本次未私自向共享 JSON 契约新增字段，也未宣称已有模板编辑 UI。若后续需要把编号分隔符等新增为通用可调字段，先按架构规则记录契约演进方案。

当前包含一套文字标准及A1三栏、A2三栏、A3两栏模板。新增个人标准使用独立ID及对应模板引用，不能覆盖另一人的标准；三图幅的格式尺寸一致，只调整布局。
