# T13 普通用户图形化安装包

状态：进行中（2026-09-25 开始）。前置：T12 正式验收、T14 功能宿主验收未完成；本任务只开发安装/升级/卸载入口与打包，真实全新电脑验收由用户执行，未验收前 `productionReady=false` 不变。

## 目标与范围

- PRD NFR-006 / 3.3：面向普通设计人员的单一发布包图形化安装；安装、升级、卸载均无需 GitHub、命令行或手工复制 `.bundle`；部署成功后重启 AutoCAD 即可发现插件；环境不满足时给出明确原因，不降低 CAD 或单位电脑安全策略。
- 修改范围：新增安装器工程、build.ps1 打包集成、用户指南与验收记录；不改共享协议、依赖与技术栈（不引入 WiX/Inno 等新依赖，复用项目现有 .NET Framework 4.8 WinForms 能力）。

## 方案（2026-09-25 定）

1. `Justified.SpecificationReflow.AutoCAD.SetupCore`（netstandard2.0，无新依赖，仅复用已在用的 Newtonsoft.Json）：包清单解析与校验、安装计划（目标路径/备份命名）、环境检查判断。纯逻辑 + 注入文件源，双框架单测。
2. `Justified.SpecificationReflow.AutoCAD.Setup`（net48 WinForms 可执行，不引用 AutoCAD API）：向导四页（欢迎→环境检查→安装→完成），另支持 `--uninstall` 卸载向导。安装前按 SHA256.json 校验包完整性；升级时把旧 `.bundle` 备份为 `.bundle.backup-<时间戳>`；复制到当前用户 `%APPDATA%/Autodesk/ApplicationPlugins`；向“应用和功能”注册卸载入口（HKCU，无需管理员），卸载程序复制到 `%LOCALAPPDATA%/Programs/<产品名>`，UninstallString 用 `cmd /c ... && rmdir` 连卸载带自清理。
3. 界面遵循 `docs/VISUAL_SPEC_V1.md`（与 CAD 选择窗口同一套颜色/字体/间距），界面字体从随包 `Contents/Windows/fonts/NotoSansSC-VF.ttf` 私有加载，与 UI_TYPOGRAPHY.md 一致。
4. build.ps1 `-Target Package`：ZIP 根目录由“仅 .bundle 文件夹”改为“.bundle 文件夹 + Setup.exe + SetupCore.dll”；用户双击 Setup.exe 即走图形安装；校验仍由 verify-package.ps1 对 bundle 执行，Setup 文件在 bundle 之外，不参与 bundle 清单。
5. 顺带硬化 `scripts/prepare-manual-validation.ps1`：另产出 `restore-filedia.scr`，验证脚本被打断时可一键恢复 FILEDIA（T11 复发根因）。
