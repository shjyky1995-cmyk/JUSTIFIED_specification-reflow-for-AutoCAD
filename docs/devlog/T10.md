# T10 — Word 到 CAD 命令

## 2026-09-22：领取

- 输入：T09 的放置和写入。REQ-CAD-002、REQ-UX-001，AC-11、AC-12。
- 输出：命令 `DN_NOTE`。解析、换行、放置都走已有端口；写图在文档锁里做一次事务。
- 范围：PluginHost、Standards 的草案内存读取、Application 的生成编排、测试说明。不改草案文件，不降低安全设置。

## 2026-09-22：命令

- `DN_NOTE` 选择 DOCX、drafts 目录、A1/A2/A3 和必须手输的单位比例，再点一次说明区右上角。拾取点按当前 UCS 转到世界坐标，文字旋转保持 0。
- 草案的 pending 只在内存里补成可计算的值，并打印 DN_NOTE_DRAFT。磁盘上的 json 不变，正式目录仍然拒绝草案。
- 解析或排版错误不写图。警告先显示，要输入「是」才写入。第二次生成不删除旧字。一次 U 撤销本次提交。
- 演示样本是「测试文件/示例-单行说明.docx」。它没有上下标。「示例-结构说明.docx」含上下标，命令会整篇拒绝。
