# T11 — 限额、运行报告与部署

## 2026-09-22：领取

- 输入：T10 的正式命令入口。REQ-OPS-001，AC-13～14（限额、运行报告、离线包）。
- 输出：单次生成限额、本地运行报告、离线打包与部署文档所需的剩余项登记。
- 范围：Contracts 限额参数、Application 限额与报告组装、Standards 编解码与模板枚举、AutoCadAdapter 图内设置存储、PluginHost 正式命令。不改共享协议语义，不改变依赖方向。

## 2026-09-22：限额与报告

- 限额：`GenerationLimits`（MaxPages/MaxTexts/MaxBlocks/MaxCharacters）在解析后、布局后、放置后三个检查点执行，超出以 E_RESOURCE_LIMIT 拒绝并清空 Texts，不截断、不落图。限额为 null 时保持旧行为（兼容 DN_NOTE_DEV）。
- 运行报告：`NoteRunReport` 记录开始/结束时间、耗时、图纸、文档、标准与模板 id/version、图幅、单位比例、成功与是否提交、页数、对象数、告警/错误码、文字包围盒。宿主在报告目录非空时写 JSON；写失败只告警不阻断生成。
- 检查：核心测试双框架 131/131（新增 14 个：设置往返/损坏/Problems、四个限额触发点、限额内生成、无限额兼容、报告字段、模板枚举/取消）。宿主编译 0 警告。
