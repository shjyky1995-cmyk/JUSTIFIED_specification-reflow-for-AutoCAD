## 2026-09-22：换行

- 规则版本 `jsr-linebreak-1.0.0` 只写在引擎里。草案仍是 pending，引擎拒绝 pending 和不认识的版本，也拒绝未标定模板。测试在内存里注入该版本、测量公差和已标定状态。
- 分词：汉字单字、英文单词、数字，以及最长工程 token（C30、HRB400、Φ20@200、0.10g、35mm、20kN/m²、1/1000、GB 50010-2010、GB/T 50011-2010）。不拆代理对。制表符和嵌在文字中的换行直接失败。
- 断行：整行交给测量接口，不用字数乘字高，也不把各字宽度相加当作行宽。行首禁则是 ，。；：！？、）】》〉”’ 及对应半角；行尾禁则是 （【《〈“‘ 及对应半角。超长 token 才按字素拆开并给出 W_TOKEN_SPLIT。单字放不下或禁则无法成行时返回 E_NO_LEGAL_BREAK，不产出页面。
- 编号：标签加两个 U+0020，只出现在首行，并至少带上第一个正文单元；放不下就失败，不缩字、不删空格。自然换行不重复编号。显式 `\n` 结束当前行，连续硬换行保留空槽。
- 上下标没有标定缩放，直接 E_TEMPLATE_INVALID，不改成普通文字。
- 字高、宽度系数、行距、缩进和栏宽都读当次配置。栏宽变化时，未消费的文字按新栏宽再测。
