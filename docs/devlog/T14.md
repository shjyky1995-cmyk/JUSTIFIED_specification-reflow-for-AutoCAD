# T14：CAD 内每次选择本次说明

## 2026-09-24：需求与实现

- 负责人：当前 Agent。输入：用户要求同一 DWG 可先后导入不同图幅、模板版本和 Word 说明；现有 T10/T11 正式排版落图链路。输出：`DN_NOTE` 小窗口和明确复用上次选择的 `DN_NOTE_REPEAT`。
- 选择窗口复用 WinForms（架构已允许），从 `DirectoryPackageCatalog` 列出 production/calibrated 模板，先选图幅，再选模板 ID/版本；选择本次 DOCX 并填写已核对的单位比例。上次选择仅预填。提交前仍走正式 `Load` 校验，模板摘要与实物图幅不一致时拒绝。
- `DN_NOTE` 选择后更新图内最后一次选择，再调用原有生成链路。一次生成不会删除先前的说明；用户下次可重新选择同图的另一图幅/Word。`DN_NOTE_REPEAT` 保留不打开窗口的快捷路径。原 `DN_NOTE_SET` 保留给旧图与 T12 验收脚本，原始 T12 私有转移 ZIP 不含新窗口。
- 当前 `PaperCode` 契约和模板 enum 仍只支持 A1/A2/A3。窗口从目录列示图幅是为了避免 UI 写死图幅；未来新增图幅仍需模型/模板/字体与宿主验收，不能只放一个 JSON 文件就宣称可用。
- 检查：`scripts/build.ps1 -Target All` 通过，0 警告；net8.0/net48 核心测试各 143/143。尚未进行真实 AutoCAD 2021 窗口交互、取消、同图混合落图检查，状态进行中。

## 宿主待验

1. 用独立候选包加载 AutoCAD 2021，在空白图执行 `DN_NOTE`，查看图幅与模板版本是否来自已发布目录；选择 A1 和第一份 DOCX 后点位生成。
2. 再执行 `DN_NOTE`，改选 A2 或 A3 与另一 DOCX，点另一处。观察两组 DBText 均保留、各自分栏续页与图幅对应；再次打开窗口应预填上次选择，但仍可改选。
3. 取消窗口与取消点位分别检查没有新增文字；输入不存在的 Word、无效单位或无效模板应明确报错且不落图。记录命令输出、运行报告和图面截图；未实测不标通过。
