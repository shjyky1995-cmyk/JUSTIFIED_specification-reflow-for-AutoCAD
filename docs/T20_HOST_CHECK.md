# T20 CAD 导入窗口验收（AutoCAD 2021）

先退出 AutoCAD。本机可直接双击 `测试文件/程序/Setup.exe`：构建脚本现已把完整 `.bundle` 放在它旁边并校验；也可完整解压 T20 候选 ZIP 后双击解压目录根部的 `Setup.exe`。安装器会备份原插件。重新启动 AutoCAD 2021，在一张空白测试图执行 `DSS`。

1. 看窗口是否约为参考稿的紧凑比例：页眉、Word 文件、四张图幅卡、三档比例和页脚各在自己的区域，文字无截断或遮挡；左上角为项目现有图标。可拖动页眉。
2. 点「更换」选择本机 DOCX；切换 A1/A2/A3 和 1x/100x/1000x，再点「其他比例」看能否输入实际比例。图幅与比例应有明确选中态；未知单位不要猜。
3. 点击「取消」，确认图纸没有新增文字。再次执行 `DSS`，选好文件、图幅和正确比例，点「在图纸中点位置」，再点图面左上角测试位置；命令行应出现 `DN_NOTE_OK`。

若窗口与 [Figma 参考截图](assets/cad-note-picker-figma-20260927.png) 比例不符、出现遮挡、按钮无法用或命令报错，请提供窗口截图和 F2 命令行文字。此验收只针对 T20 界面及入口；旧版打印成果由用户另行反馈。

本次 1.1.1 几何修订的打印复核：使用同一 DOCX、图框和图幅重新生成 A1/A2/A3（可先做平时最常用的一种）。查看每一栏的最后一行是否全在下方图签上方，且至少有一行高度的空隙；上方首行也不能碰图框。若不符合，保留 PDF，并告知图幅、比例和在图面点选的左上角位置。旧的 `0927/A2-1.pdf`、`A3-1.pdf` 是修订前证据，不能当作 1.1.1 的通过证据。
