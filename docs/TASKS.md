## 双端与界面顺序（2026-09-24，规划，不扩大 V1）

1. **先打通 CAD 产品流程**：完成 T12 性能定位和优化、剩余图面/打印/断网/业务验收；完成 T14 每次选择的功能验证；实现并验证 T13 图形化安装/升级/卸载。A2 点位后约 21 秒的反馈属于性能问题，不能因推迟视觉改版而延期到正式推广之后。
2. **再统一界面设计**：功能和安装流程稳定后，先定义桌面端与 CAD 端共用的视觉规范（颜色、字体、间距、控件状态、错误与进度提示），再改 CAD 小窗口。CAD 端仍须保持每次选图幅/模板/DOCX、核对单位、点一次位置的短流程；视觉签收在普通用户正式推广前完成。用户当前不要求立刻重做窗口。
3. **后续桌面应用**：现有 PRD 将独立桌面工作台列为 V1 以外。Electron 是用户提出的候选技术，用于 Windows 桌面应用的现代界面；具体业务功能、与 CAD 的交互、打包方式和技术栈变更须在进入桌面阶段时形成小原型与决策记录，经用户确认后实施。不得为此预建空服务或把桌面端计入当前 V1 完成度。

### CAD 选择窗口视觉概念 V1（用户 2026-09-24 提出设计请求）

最新视觉稿：[CAD 导入说明窗口 V2](assets/cad-note-picker-concept-v2.png)；[V1](assets/cad-note-picker-concept-v1.png) 留作修改历史。2026-09-25 已按 V2 在 WinForms 实现候选，视觉稿仍不是实测截图。用户提供的三段式几何 logo 仅用于图形参考，品牌中文名仍待确定；不要把草图中的名称写死在程序或安装包里。

- 目标是极简、现代、少文字但易懂：图标配短标签，不用仅有图标的隐语；浅色卡片、黑灰文字、单一蓝色主操作色。桌面端未来沿用颜色、字体、间距、图标与状态文案，CAD 端保持紧凑。
- 2026-09-25 最终日常窗口改为三项：Word DOCX、图幅、单位比例。A1/A2/A3 以 3/3/2 栏卡片展示；第四张“更多”卡片只列未来已验证的其他图幅，不能把当前不支持的图幅假装可用。标准包与模板版本由安装或管理设置确定；每图幅须有且仅有一份有效模板，多套标准冲突时明确阻断并提示管理员，不静默换标准。
- 两步交互：窗口内“选择” → 点击“在图纸中点位置”进入 CAD 点位；点完直接生成并自动收起窗口，无第三个“完成”页面。上次选择可预填但每次可改。
- 无警告时不再加一次确认；无效文件、缺模板或未知单位必须在窗口中明确阻断。生成中的进度与取消、失败时的原因要有清楚状态；不编造预计秒数。
- 实施时先确认现有 WinForms 宿主在 AutoCAD 2021 的缩放、键盘、焦点及高 DPI 表现，再决定如何实现视觉稿；若考虑更换 CAD 内 UI 技术，按架构变更规则先记录并确认。视觉稿中的 logo 是近似示意，正式使用须取得用户确认的原始标志文件与名称。
