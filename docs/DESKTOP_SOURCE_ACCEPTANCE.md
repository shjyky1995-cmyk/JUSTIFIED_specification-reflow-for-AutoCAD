# 桌面完整原稿试用

## 入口

关闭旧桌面窗口后，双击项目根 `content-library/private/启动自动说明试用.cmd`。新建说明，选对应专业和模板；已有草稿仍保留原内容，要看本轮结果需重新选择模板，并确认覆盖提示。原工程文件没有改动。

## 查看

1. 在编制页查看：正文与表格应按原件交错排列，不把表格集中放章节末尾。
2. 填本章上方工程取值；表内取值同步显示。一般正文完整保留，可以展开修改文字。
3. 预览确认章节完整、表格位置一致。缺项应提示并阻止正式导出；核对适用性与规范后才能确认。
4. 导出DOCX，用Word/WPS打开：表格应可编辑、宽度在页内、长表重复表头。不得把自动测试文件的“测试值”当成本工程数据。

七套来源模板：结构水池、框架、水池＋框架、建筑、给排水/工艺、电气、暖通。钢结构与其他没有对应来源，不生成虚构正文。

## 当前证据和限制

已通过七份原件1355章内段、29表的顺序与固定正文核对，以及七模板DOCX实际生成和读回。字体采用桌面统一输出样式，不承诺原Word逐像素复刻；CAD内字体、行高与表格线由CAD自己的模板设置。

本机缺少文档渲染组件，Word/WPS分页及真实窗口待用户核对。原件工程结论与规范适用性仍需核定，自动识别变量不等于专业审查通过。出现缺段、取值不对应、溢出等问题，反馈模板名、章节、表格/段落位置即可。
