## 可确认的页面结构

| 页面 | ZIP 与截图呈现 | 本阶段的作用 |

| 首页 | 品牌、设置/头像、搜索；三张文档入口（设计说明、可研报告、投标文件）＋两张横向入口（项目管理、AI 工程助手）；当前项目、最近工作 | 启动默认首页；本阶段仅设计说明进入可用流程，其余入口清楚标注未开放 |

首页截图和 ZIP 均显示启动默认 `home`、点击「设计说明」进入新建流程、关闭返回首页。历史对话中“默认直接进入设计说明、首页变成占位页”的描述指更早版本，**不适用于这版 ZIP**。

## 原型与成品的区别

- ZIP 是 React/TypeScript、Vite、Tailwind 的 UI 原型，可作为视觉和组件拆分参考；不是现有 CAD 项目的代码，也不是已完成的桌面产品。
- 首页项目与最近工作、章节与预览正文均为写在页面里的示例数据。只有「设计说明」卡片连到新建流程；其余卡片和搜索未接业务功能。
- 专业按钮在原型中始终把「结构」画成选中；项目输入不保存。所有模板卡片进入同一静态编辑页；切换章节只改变选中高亮，右侧仍显示同一示例正文。
- 「已自动保存」由一秒定时切换显示，没有持久存储；「导出 Word」按钮没有导出操作。成品验收必须证明关闭重开仍可恢复正文，且导出文件与预览一致。
- 原型引入在线 Google Font 和外部头像图片，界面还有 macOS 的 `⌘K` 提示；Windows 离线成品应使用随包或系统允许的资源及正确快捷键。示例正文中的 `[Table Block Placeholder]` 不是当前表格支持承诺。

## 使用边界

这版设计稿确认了首页信息架构、三步流程和视觉方向。章节内容、项目数据、专业参数来源、模板适用规则、自动保存语义及 DOCX 输出均须以 PRD 和后续真实样本验收。桌面端交付到可编辑 DOCX 即止；用户再自行用现有 CAD 插件选择文件，桌面端无 CAD 连接或同步任务。
