# T14 不同 DOCX 与点位取消验收（本机）

T14 剩余两项功能验收：同一空白 DWG 中使用**不同 DOCX** 分别生成；点位时**取消**不新增对象。命令已简化为 `DSS`（`DN_NOTE` 为旧别名，等价）。

## 一、不同 DOCX 验收

### 样本

本轮样本包：`artifacts/t14-docx-samples/`（本机资料，不入库）。内含 2–3 份**不含表格**的说明 DOCX（含一份与 T12 相同的 sample.docx 作基线）、每份的 SHA256 与本地解析结果。含表格的 DOCX 会被 V1 解析器按 `E_UNSUPPORTED_CONTENT` 阻断，这是预期，不算失败，但不要选作本项样本。

### 步骤

1. 新建一张空白模型空间图。
2. 输入 `DSS` → 选第一份 DOCX → 选 A2 → 单位比例 `1` → 点一次位置；记录命令行 `DN_NOTE_OK pages=… objects=…`。
3. 同一张图再输入 `DSS` → 换第二份 DOCX → 可改选图幅（如 A3）→ 另找一处点位；再记录一行 `DN_NOTE_OK`。
4. 检查：两份说明文字都在图面、互相不覆盖；旧文字不被第二次生成改动或删除。
5. 对第三份样本重复一次（可选）。

### 回传

- 每份样本一行 `DN_NOTE_OK`（或开启 `DN_NOTE_TRACE=1` 时的完整输出）；
- 图面截图（能看到两份说明共存）。

### 通过标准

每份样本都能独立生成成功；同图多份共存不互相破坏；改选图幅生效。

## 二、点位取消验收

### 步骤

1. 新建空白图。如需测“生成中取消”，先用大文档（样本包内 `cancel-large.docx`，约 190 段）拉长生成时间。
2. 输入 `DSS`，正常选择 DOCX/图幅/比例，点“在图纸中点位置”。
3. **在图纸上点位之前**按 Esc：应显示 `DN_NOTE_CANCELLED`，图面零新增。
4. （生成中取消）再次 `DSS` 并点位置，生成过程中立即按住 Esc：应显示 `DN_NOTE_CANCELLED`，随后图面零新增（可用 `QSELECT` 或选择全部文字核对数量与操作前一致）。

### 取消验证标准

两种取消都显示 `DN_NOTE_CANCELLED` 且图面零新增。任一次取消后残留文字即不通过，记录复现步骤交 Agent。

### 回传

- 取消时的命令行截图；
- 取消后对象数量核对方法（QSELECT 条件：对象=TEXT，层=JSR_NOTE_TEXT）。

### 通过标准

两种取消都显示 `DN_NOTE_CANCELLED` 且图面零新增。任一次取消后残留文字即不通过，记录复现步骤交 Agent。
