# T12 一次真实打印核对（本机）

目标：确认真实打印机/PDF 输出上图面正确——分栏、续页、上下标、钢筋符号、无乱码、无越栏。屏幕核对通过不代表打印通过，本项独立签收。

## 准备

1. 用 T12 三图幅验收生成的任一张测试图（A1/A2/A3 各一张最佳；若已关闭，按 `T12_ACCEPTANCE.md` 重新生成）。
2. 打印机就绪。没有物理打印机时用系统“Microsoft Print to PDF”（打印到 PDF 后逐页看图），效果等同图面核查。

## 操作步骤

1. 打开测试图，`ZOOM` → `E` 看全图，确认屏幕上方就已无乱码、无越栏。
2. 输入 `PLOT`（或 Ctrl+P）：
   - 打印机选目标打印机或“Microsoft Print to PDF”；
   - 图纸尺寸选与图幅一致（A1/A2/A3 对应 mm 尺寸）；
   - 打印范围选“窗口”，框选全部说明页面；
   - 居中打印勾选，比例 1:1（图形单位 = mm 的测试图）；
   - 打印样式表用默认 acad.ctb，不要替换。
3. 打印/导出后逐页核对下面的清单。

## 核对清单（每页）

- [ ] 页序正确：页面向右排列，续页接续上一栏/上一页，无跳页、无空白尾页
- [ ] 分栏正确：A1/A2 每页三栏、A3 每页两栏，栏间无明显文字越栏
- [ ] 文字清晰：无“？”方框、无重叠、无半个字；行距均匀
- [ ] 上下标正常：`N/mm²`、`m³`、`10⁻⁴` 位置和大小正确
- [ ] 钢筋符号正常：`Φ20@200` 不断线、不变形
- [ ] 标题与页码说明（如有）位置一致

## 回传内容

- 每种图幅一张打印/PDF 截图（含整页）；
- 打印机名称与驱动版本、图纸尺寸设置；
- 任何一页不合格的放大图与页码。

## 通过标准

三种图幅全部页面清单项通过，无未解释异常。任一项不过：记录页号与现象，交 Agent 定位（区分“屏幕显示问题”与“打印/驱动问题”：屏幕上对、打印错，通常是打印机驱动或打印样式，先换“Microsoft Print to PDF”复现）。
