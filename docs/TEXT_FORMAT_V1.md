# 项目说明文字格式 V1.0

生效日期：2026-09-22。规则版本：1.0.0；standardId：jsr-note。

## 决策依据与适用范围

用户明确授权：院内没有完整排版标准，只需沿用已有字体，其余文字格式由本项目统一制定。本文是据此制定的规范性决策，不是历史图纸的测量结论，不再要求从旧图找出完全一致的字高、行距或缩进。PRD 中“院标”在本项目指这份项目标准，不要求外部院标文件。

适用于本程序新生成的 A1/A2/A3 说明文字。Word/WPS 负责内容、层级和编号语义，不能覆盖本规则的 CAD 外观。本次不批量修改历史 DWG，也不更改 AutoCAD 安全设置。字体文件不随仓库分发。

## 固定格式

下列长度均是标准坐标中的毫米。选择 4.5 和 7.2 是本次设计决策，参考样图常见 450/720 与其 1:100 图框标记，不代表已证明该图实际按 1:100 打印。

| 项目 | V1.0 固定规则 |
|---|---|
| 西文字体 | tssdeng.shx |
| 中文大字体 | tssdchn.shx |
| 正文、一级标题、二级标题、编号字高 | 一律 4.5 mm |
| 宽度因子 | 一律 0.75，度量与绘制只应用一次 |
| 倾斜角 | 0° |
| 文字方向 | WCS 水平、旋转 0° |
| 基线行距 rowPitch | 7.2 mm；不用旧图辅助行格的 7.21 mm |
| 标题段前/段后额外槽 | 均为 0；标题按实际换行数占槽 |
| 正文与标题首行位置 | 栏左边界，indent=0 |
| 正文与标题续行位置 | 栏左边界，indent=0；不做悬挂对齐 |
| 编号位置 | 首行文字内联“编号＋两个半角空格＋正文”；hangingIndent=0，无独立编号区 |
| 无编号段落 | 从栏左边界开始，不添加编号分隔空格 |
| 文字样式名 | 沿用现有命名规则 jsr-note-1.0.0-heading1 / heading2 / body；三者外观一致，STYLE 固定高度为 0，实体显式写入上述字高 |
| 输出图层 | JSR_NOTE_TEXT；新建时颜色 ACI 7，实体颜色 ByLayer |
| 输出实体 | DBText；上下标按已验证的分段规则处理，不能降级成普通数字 |
| 空行 | 仅源文档明确空行消耗槽位；不因标题层级自动加空行 |

统一格式不改变原文内容、编号或层级，不添加原文没有的标题编号。用户后续明确选择内联编号，取代本轮早先拟定的 13 mm 预留区方案。首行示例为 `1.1  材料要求`，两个分隔字符均为 U+0020 半角空格，不使用 Tab 或全角空格；无悬挂缩进，续行回到栏左边界。

编号属于该首行的正常文字前缀；普通文字场景作为同一个 DBText 字符串输出，不为编号另外建定位实体。若正文含需分段呈现的上下标，仍允许按原契约输出必要的 DBText 分段，不为追求单实体而丢失语义。

自动编号先按已支持的编号定义得到显示编号，再拼接一次分隔空格；已被解析器明确识别的手工编号只规范编号与正文之间的分隔空白，不能重复添加编号或标点。正文内部空格及其他内容保持原语义，不凭字符串外形重新猜测编号。没有可靠识别的手工编号按原输入规则诊断，不能静默改正文。

编号、两个空格与正文共同参与真实字体测量和行宽计算，不能按字符数估宽；编号前缀至少与首个可排版正文单元共同放入一行，避免编号孤立，不能容纳时明确诊断，不缩字、不删空格。自然换行后不重复编号，显式源换行仍保留。

同名样式或图层与规则冲突时报告冲突，不能覆盖既有对象或悄悄换字体。字体缺失仍阻断生成，不接受 AutoCAD 替代字体作为通过。标题仅通过语义层级与原有编号区分，不额外加粗、放大或增加占行。

## 字体身份与尺度

本机已通过 AutoCAD findfile 找到两个字体；路径只是本机环境证据，不得硬编码到发布包。当前校验身份：

- tssdeng.shx SHA256：AD342B3A0AE26923C7A4FD1F7F885BDD5CDDAC8D10B48CBD41C490BFE05745B5
- tssdchn.shx SHA256：A55FBC7AB693E59FEBC2640FD974ACCED774686C5858308B4BCC00C1895A2CA6

标准长度不直接等于任意 DWG 的实体数值。落图时必须使用显式确认的 unitScale（每标准毫米对应的图形单位数）等比转换字高、行距、缩进和栏坐标：实体字高=4.5×unitScale，行距=7.2×unitScale。unitScale=1 时分别为 4.5/7.2；明确选择 100 时才为 450/720。目标 DWG 单位未知时仍按 PRD 阻断并要求明确比例，不从图框名或默认设置自动猜测，也不自动改 UNITS。实际打印比例及纸面结果单独核验。

## 已定规则与仍需验证的边界

上述字体组合和数值已经是实施依据，后续 Agent 不得继续把“等待院内统一字高/行距/缩进”列为阻塞，也不能未经记录擅自换回测试夹具值。变更这些规则须追加版本和原因。

文字格式与三图幅布局均已制定，具体容量由项目规则明确选定并验证几何，不把历史行格数当成自动发布依据；不要求逐项复刻旧图。旧图原始证据保留在实测报告，不能篡改。

字体字形、特殊字符、上下标尺寸/偏移和测量公差仍需真实宿主及打印验证；本文没有伪造这些验收结果。Word/WPS 样式别名与源文档编号方式仍属于输入语义，不能从 CAD 字体推导。

实施状态：格式规则已制定，运行时标准包尚未发布。不得把本文直接冒充通过 AC-05/06 的完整生产 JSON。后续依既有契约实现包并完成验证；本次未改共享契约、依赖或技术栈。

## 多套标准与可调整模板入口

字体格式（standardId/version）与图幅模板（templateId/version）分离，模板通过 standardRef 引用确切格式版本。后续调整字体、字高、宽度、行距、缩进时新增标准版本；调整图幅、栏数、栏宽、栏间距、首基线、每栏行数或续页步长时新增模板版本。不得把本次三栏、71 行、7.2 mm 等写死在引擎里，也不能覆盖已发布版本使旧结果无法复现。改规则后重新校验、测量和排版，再完整重出；不引入历史 DWG 增量追踪。

本项目主动制定完整院标；不同机构或个人使用独立 standardId/version，可独立选择和修改，不限定只有一套标准。当前 A1/A2 为三栏、A3 为两栏，字高不随图幅变化，具体规则见 [三图幅模板](PAPER_TEMPLATES_V1.md)。可编辑草案存于 standards/drafts，发布通过后进入 standards/published。这是现有契约内的配置扩展入口，不代表已经实现可视化模板编辑器；本次不扩大 V1 UI 范围。
