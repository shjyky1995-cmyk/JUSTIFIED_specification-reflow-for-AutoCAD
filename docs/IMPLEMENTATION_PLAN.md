## 现状与技术边界

- CAD v0.1.0 已发布，`DSS` 保持独立；桌面与 CAD 仅通过用户选择的最终 DOCX 衔接，不增加桌面到 CAD 的接口。现有 DOCX 解析器可用于桌面导出后的兼容性自动检查。新版 CAD 打印 PDF 待用户后续反馈，不阻断桌面规划。
- T16 分支 `task/T16-desktop-authoring` 有 Electron/React 骨架与 .NET 10 DOCX 生成/检查进程。构建和生成/读回测试通过；真实窗口未验、未合入 main。保留可用技术基础，旧固定栏目表单按新 PRD 替换。
- 专业内容与框架分离：每份说明保存专业、项目快照、模板/章节版本和当前正文副本；标准库版本化、本机离线保存。用户后续补充专业正文时，不需重写页面与存储协议。共享协议、模块依赖、技术栈如需改变，先记原因与影响再商量。

## 三个大阶段

| 阶段 | 一次性交付范围 | 阶段验收 |
| --- | --- | --- |
| A 通用编制框架 | 首页与导航、项目/草稿、六专业选择及条件参数、可用章节组合、纯文本编辑/自动保存、连续预览和 DOCX 导出；恢复草稿、错误状态与桌面实际窗口 | 自动化逐专业走通新建→章节→预览→导出→解析器读回；非结构无结构字段；关闭重开不丢保存内容；UI 无遮挡；Agent 先自测、修复并提交，用户只看一次阶段成果 |
| B 标准内容与专业深化 | 用户后补的章节正文/模板按版本导入；优先深化结构参数、变量与材料方案；抗震数据只在可靠来源授权和核验后接入 | 用脱敏真实样本检查章节、变量和 Word/WPS 修改后的 DOCX；来源、版本及未覆盖地点可追溯；缺内容不冒充正式规范结论 |
| C 成品交付 | 统一视觉细节、离线安装/升级、高 DPI、使用指南和发布材料 | 普通用户无需命令行完成编制与导出；自动测试、桌面安装检查和用户试用分别记录；用户集中完成一次最终验收；仅脱敏材料进入公开仓库 |

前期已核对用户提供的 Figma Make 源码 ZIP 与五张页面截图，页面结构、原型行为与未实现项见[设计参考核对](FIGMA_DESIGN_REFERENCE.md)；本计划与[抗震数据来源调研](SEISMIC_DATA_SOURCES.md)一同供用户审阅。A 阶段启动后内部不再拆成多次用户验收；通过相关检查再交付。专业正文由用户后期统一补充，**A 阶段不依赖它**，测试使用明确标识的脱敏演示内容。没有可靠地点数据时结构界面显示「待核定」，不自动填入烈度。

主要已知风险：ZIP 和截图能证明这版原型的页面与代码结构，但不能代替后续真实桌面窗口的交互、离线资源和可用性验收；原型的项目数据、保存与导出并未实现。抗震开源仓库尚未发现可直接当权威生产数据的完整授权表。两项均不妨碍先定框架；不能写成已验收。
