# 「设计说明」实施计划（评审稿）

日期：2026-09-27。对应 [PRD](PRD.md)。**先确认本稿，再恢复业务代码开发**；不以 Figma 源码直接替换现有工程。阶段内连续完成实现、测试、修复、日志和提交，按 `WORKFLOW.md` 验收。

## 现状与技术路线

- CAD v0.1.0 已发布；现有 `DocxAdapter`、结构化模型和 `DSS` 可复用。新版 CAD 打印 PDF 仍待用户后续反馈，不阻断桌面文档规划。
- T16 分支 `task/T16-desktop-authoring` 已有 Electron/React 界面骨架及 .NET 10 固定栏目的 DOCX 生成/检查工作进程；构建和生成/读回测试通过，**真实窗口与完整按钮流程未验收，未合入 main**。新需求取代「固定栏目填写后主要靠 Word 修改」作为桌面主流程；可复用文件写出、读回及安全桥接，但需替换业务表单。
- 技术栈维持已定 Electron + React/TypeScript、.NET 10 本机工作进程。两者只在桌面应用内部通信；CAD 插件保持 net48 与独立 `DSS`。项目草稿本机保存，标准库以版本化数据包加载，不建云服务。共享协议/依赖变更先记 ADR 并讨论。

## 阶段与验收

| 阶段 | 实现顺序 | 验收关卡 |
| --- | --- | --- |
| P0 需求冻结 | 用户审阅 PRD、Figma 首页/四个设计说明状态及两项待定规则；建立脱敏结构说明样本 | 业务规则与 UI 差异被标注；样本无个人/机构敏感信息；不在此关卡承诺 Figma 尚未核对的像素细节 |
| P1 应用骨架与草稿 | 恢复首页导航、说明列表；定义项目/参数/说明/章节版本数据；本机原子保存与恢复 | 新建、退出、重开、断电模拟、保存失败均不丢已确认内容；首页不被占位页取代 |
| P2 参数与章节 | 01/02A/02B；标准库、默认组合、自定义章节、顺序、变量生成、当前副本编辑和重置确认 | 组合可加减排序；修改副本不污染标准；返回参数取消/确认行为正确；长中文和窗口缩放不遮挡 |
| P3 预览与 Word | 03 连续预览、DOCX 导出、Word/WPS 回写和解析器读回；用脱敏结构样本走通 | 预览/Word 顺序与文字一致；重名不覆盖；文件经 Word/WPS 保存后可由现有 CAD 解析器读取；不支持内容有定位提示 |
| P4 交付验收 | 桌面安装/升级、离线与高 DPI 检查；用户在 CAD 手动选 DOCX 落图；修复真实反馈 | 普通用户无需命令行完成主流程；CAD 真实字形/图幅检查独立记录；发布只含脱敏资产 |

每阶段先做核心数据与错误路径，再接 UI；目标目录为 `desktop/app`（页面/状态）、`desktop/worker`（编制与导出）、`desktop/standards`（版本化标准数据），确需拆库时另记决策。自动保存采用短时合并写入、临时文件写完后替换、失败保留未保存状态；导出从已保存的当前说明快照生成并读回验证。模板 ID/版本与当前副本分离，避免标准更新覆盖用户正文。

主要风险：真实结构章节/变量样本尚缺；抗震地点映射未核验；Figma 当前画面未由本次连接直接取得；T16 真实窗口尚未运行验收。这些分别在 P0/P2/P3 检查，不用猜值或假证据填补。P0 定稿后从 T16 checkpoint 接续；不先合入过时的固定表单版本。
