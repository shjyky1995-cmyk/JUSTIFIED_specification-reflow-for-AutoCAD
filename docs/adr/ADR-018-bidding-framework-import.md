# ADR-018 易标框架移植与独立运行

日期：2026-10-06；任务T38。用户明确要求原框架直接搬入、先适配UI再逐步改进，替代T33只参考自行实现的路线。

用户已确认两项关键选择：保留原Electron41作为独立投标模块；统计及失败诊断留本机，关闭向作者服务器自动上传。无需重复审批。

原作者OpenBidKit / 易标（mark / yibiaoai），本地只读参考固定f185a25bec6709c9132c4f874d5d824e93acac84。复制client、openxmlhelper、sql，保留AGPL-3.0-only LICENSE/NOTICE，UPSTREAM.json保存原文件哈希。移植模块不是自行重写；现有CAD/设计说明的许可不自动改写。候选附对应源码，正式公开发行前核对组合发布许可和依赖问题。

## 选择原因与边界

- 现有客户端Electron44.4.5实测ABI149；原框架41.10.2/ABI145的SQLite组件无法直接共享，本机缺重编译所需C++工具。模块使用独立进程相当于主软件打开一个专门的投标窗口，退出后返回工作台；原框架业务仍运行在适配的原环境里。
- 主程序入口等待子窗口加载后隐藏，子进程退出恢复主窗口；不依赖浏览器/Python/Node/SDK，便携包自带运行时、Agent工具和.NET10 Word助手。
- 新模块数据在同包portable-data/data/bidding-framework（以主程序dataRoot为准），SQLite/原件/配置/本地统计共存；旧版JSON投标稿保持原目录和独立入口，不自动混写/迁移。
- 复用现有品牌图标、字体、配色、按钮和卡片，保留上游技术方案七步及其他现有模块。施工/通用内容先按原版来，未完成的原版入口保持原状，不冒充已完成勘察设计专用业务。
- agnet.top、yibiao.pro及其子域的请求在主进程fetch/undici和Chromium session阻断；/track内容写本地events.ndjson，许可等仅记录路径；Agent失败报告独立进程压缩/密钥脱敏后留本机，不上传。自动更新和IP封禁检查不运行；不伪造原作者商业许可。
- 用户主动配置AI/解析服务再使用时按原版流程联网，配置自己的服务。新模块不继承旧版的逐次发送预览承诺；要用脱敏文件核验发送范围。已移植配置机制，不自动填密钥，不运行真实付费测试。

## 核验与剩余项

源码前端编译、SQLite原生库、文件选择/取消/TXT保存回读、实际主入口/关闭、原导出器及自包含OpenXML助手DOCX正文/表格读回、本地统计/诊断/密钥脱敏均有自动证据。组合包、真实API、用户文件/Word视觉验收逐项记录T38日志；没有证据的不记通过。

原版锁定依赖审计52项（含3严重），候选仅本机测试，正式发行前审查可达依赖和升级兼容性。OpenXML助手编译有原版空引用警告；原版部分业务仍未完成。下一阶段按真实勘察设计标书细化目录、要求/响应及材料组织，不同时改动设计说明工作线。
