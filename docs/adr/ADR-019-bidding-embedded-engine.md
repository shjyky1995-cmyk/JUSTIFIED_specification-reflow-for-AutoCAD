# ADR-019 平台同主窗口投标与原运行时后台

2026-10-06，T40，接续ADR-018。用户提出平台内点击即用的子模块，在说明同窗口页面＋原Electron41引擎后台方案后回复“继续工作”。依此实施；不伪造异步选项答复或用户实测签收。CAD接口、另一Agent的设计说明源码及现有运行时版本不变。

平台Electron44用WebContentsView装入原易标前端，原SQLite/Agent/解析/Word服务在Electron41后台执行。相当于界面在平台内，专门的投标发动机在后台；避免重写原业务或把不兼容的SQLite加载到44。平台不隐藏、不替换原生主窗口；后台无可见业务窗口。

内部IPC版本1通过本机父子进程管道，消息为ready/registry/invoke/result/send/event/native-dialog/native-result/shutdown。仅转发原业务注册白名单，平台只允许自己的投标视图调用；原窗口关闭/返回用engispace专用握手。JSON带类型标记保持undefined、日期、TypedArray及ArrayBuffer，二进制Base64；不接受函数/循环引用，不开放任意代码执行、网络端口或裸文件接口。advanced跨版本通道实测挂起，JSON原型与实际DOCX预览通过，因此采用JSON。

原生选文件、保存和提示由平台主窗口拥有，后台仅传允许的选项。原图片协议限workspace下原三种目录，越界拒绝，前端来源限制及CORS已验证。关闭/返回复用原任务离开保护，清理原服务、视图及自身后台，数据目录与ADR-018兼容；后台故障显示错误并保留平台，允许重试。内嵌模式拒绝原独立GPU重启/自动升级入口，避免脱离平台另起进程。

前后台保留原上游自动外发阻断与本机统计/脱敏诊断；用户主动配置并运行的AI/解析服务仍按原版流程发送，不沿用旧JSON版逐次发送预览承诺。新模块与设计说明数据仍独立，未实现跨模块项目存储同步。

核验见T40：单窗口、44/41边界、选文件/取消、SQLite、实际Word与二进制预览、受限资源、统计阻断、返回/重入/故障/关窗。真实AI/费用、复杂Word视觉和专业业务、原锁定依赖52项风险仍pending；候选仅本机，未合main/推送/正式发行，许可署名及对应源码保留。
