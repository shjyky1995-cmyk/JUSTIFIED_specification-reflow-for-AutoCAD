# ADR-020 统一开发主线与历史分支归档

日期：2026-10-14。状态：用户确认。

## 原因与授权

用户要求检查项目进度、推进合入 main 并减少分支。说明现有人工待验项和原验收后合并规则后，用户明确选择“按建议统一到 main，保留待验收标记”。main 改为持续开发入口；正式发行依然以阶段签收与独立版本标签为依据。

## 实施与影响

- 从原 main 058ab3e 依次合并投标 T40 c4d21f0、设计说明 T32 2dcbbb1、CAD/交付 T41 2d75fb5，保留合并历史。不能以某一个工作线文件树覆盖整个项目。
- 保留 main 已签收的 CAD T20 布局及 published 标准；纳入表格协议2.0、候选标准、GDI字体修复、设计说明反馈修正、共享正文和投标同窗口模块。不改变共享协议已批准范围、技术栈或模块依赖。
- 完整编译、双框架核心、六专业/七模板DOCX、保存/参数/核对、投标本机逻辑/PDF/内嵌运行与包检查通过才合主线。具体证据以 T42 日志为准。

## 回退

旧main可通过 archive/2026-10-14/main-before-t42 找回。正式回退使用 git revert 保留历史；不得强推或重写旧提交。归档标签不是正式发行标签。
