# 勘察设计投标试用说明

版本：0.3.0-bid-preview.4；T37 AI候选来源核对与取消恢复候选，保留本地PDF与DeepSeek功能，待人工验收。

## 打开与资料位置

双击本包 `client/EngiSpace.exe`，首页选择「勘察设计投标」。无需安装 Node、.NET SDK 或 CAD。请把整个包保留在 G 盘，不要只移动 exe。此便携包没有安装器，不覆盖原设计说明候选。

便携包的数据和缓存位于包根目录的 `portable-data`，投标草稿和原件在 `portable-data/data/bids`。首次打开是空工作台；不会自动迁移旧设计说明草稿或附带私有资料库。旧设计说明客户端继续使用原入口。升级前从投标模块备份各标段，保留旧包和 portable-data。

## 一次完整编制

1. 选择勘察、设计或勘察设计联合，填写项目、标段、投标单位、负责人、期限及报价。联合业务类型与「联合体投标」是两个独立选项。
2. 「招标资料」导入 DOCX/TXT/PDF/图片，保留原件。DOCX 提取正文和简单表格，以段落/表格位置定位；文字型PDF按物理页（从封面起按文件顺序）提取，页码不等于印刷页码；扫描/空白/图片页会提示未执行OCR，需打开原件人工摘录。TXT按原行号完整提取，错误编码与超限会提示。复杂对象会列出未可靠解析的提示。逐份核对并勾选确认。补遗作为新文件导入，改为「补遗答疑」并关联旧资料；旧版继续保留，相关复核状态失效。资料版本、类型或补遗目标改变后，关联要求、资信和章节需重新核对，原正文保留。
3. 「要求与响应」从摘录建立或手工添加资格、评分、实质要求、成果、格式、提交事项，填写原文位置及摘录。可点「定位来源摘录」返回原位置，长资料每组显示20块并可切换；手工位置不匹配时仍需打开原件核对。逐条关联响应章节和证明材料。非适用项须写明原因，最后确认清单完整性。
4. 「商务资信资料」登记企业资质、人员证书、业绩等，关联已导入的原件，填写持有人、有效期及适用范围；无固定有效期须人工确认。资料过期或在投标截止前到期会提示。
5. 「章节编制」编辑、增删、排序章节和简单表格。预置章节只有结构，正文从空白开始。修改项目事实、章节或证明资料会撤销相关复核，避免沿用旧结论。
6. 「核对与导出」查看可点击定位的缺项和响应表。任何时候可导出有明确待填标记的草稿；清单全部核对后才开放「已核对稿」。在 Word/WPS 完成最终版式、专业审查和签章，另行上传电子平台。

修改自动保存，也可点击保存或 Ctrl+S。离开模块和关闭窗口会等待保存；失败时保留输入并显示错误，先解决问题再离开。不要强制结束进程。原草稿损坏/缺失时会提示使用上一成功保存版本，需自行核对。导出和备份不覆盖已有同名文件，请使用新名称。

## 备份和恢复

「备份本标及附件」输出独立 JSON，包含本标数据和全部引用原件。恢复入口在本机投标项目列表，恢复为新副本，不覆盖原稿。附件单件上限20MB、备份原件合计80MB；超限应拆分标段。文件内部保存SHA256用于完整性检查，不能代替资料真实性核查。

## 本轮验收（约一份脱敏小标段）

- 分别新建三种类型，确认预置章节合适；输入标题和正文后关闭重开，最后一次修改应保留。
- 导入一份脱敏招标DOCX和证明附件，建立两条要求，关联章节与证据。确认响应表能回到对应章节；改正文后应要求重新复核。
- 添加补遗，旧资料仍在、受影响状态回到待核对。空项/过期证明存在时不能导出已核对稿，但草稿可导出。
- 在 Word/WPS 打开草稿，确认项目字段、章节顺序、表格文字完整且可编辑。程序已做DOCX结构及读回检查，真实分页、字体与长表跨页尚待本次人工检查。
- 备份后恢复，出现新副本；原稿及附件仍在。异常请反馈「操作步骤＋提示文字＋所用资料类型」，可附脱敏截图。

## 本地要求候选与 DeepSeek 辅助

在「招标资料」选择文件，点击「本地提取要求候选」，逐项勾选后加入要求清单。这是关键词筛选，不调用AI；原文中的否定、条件和例外保留。候选不会自动勾选已核对，已加入的相同来源摘录不会重复添加。「要求与响应」也可点击关键词建议关联章节，再人工核对。

AI操作：

1. 打开任一标段，在页面上方选择「AI辅助与设置」。模型默认为deepseek-flash，按自己账户可用名称修改。填写DeepSeek官方API密钥并保存；不能用网页登录密码代替密钥。密钥由Windows safeStorage加密，跨电脑/Windows账户可能需重填，不发到聊天。
2. 选择「提取要求候选」「建议章节目录」或「起草章节候选」，勾选允许发送的招标文件/补遗。章节任务还要选参考章节。证明原件不参与AI自动核定。
3. 点击「预览本次发送内容」，检查全部文字后再「确认发送并生成」。文字型PDF可勾选「只发送指定物理页」并填写起止页；任务记录保留本次页范围。单次选1至10份、合计4万字符以内；超限明确拒绝，不自动截断，不上传原始附件。任务按所选模型计费，输入/输出tokens记录在任务中，金额以DeepSeek账单为准。
4. 展开任务结果，先查看每条候选的来源文件、生成时版本及原文位置，点击「查看引用原文」会定位到相应摘录组。资料版本、类型、关联原版或后续补遗变化后，旧候选显示「来源待重新核对」，禁止勾选及采纳；原结果与人工正文保留。点击「按此任务重新准备」，核对当前资料与发送范围后重新生成。旧版任务没有资料版本快照，只供查看，重新生成后再采纳。逐项选中有效候选并「加入所选候选」。引用必须能在发送原文中逐字找到；这仅证明引用存在，不证明语义或工程事实正确。要求仍待人工确认；目录/章节新增AI候选副本，不覆盖原人工正文，并保留待核定标记和来源摘录。
5. 取消发送预览会释放本次待确认记录，连续取消后仍可重新准备，不发送请求。已经发送后，即使回复正文读取中停住，也可取消或等待超时，再手动准备新任务。取消、断网、超时或软件中断不会自动重发。成功结果留在本标段任务记录，重开后可继续核对；重试需重新预览和确认。取消本地等待不保证服务端停止计费，失败用量未知不代表零费用。

任务记录在 `portable-data/data/bid-ai/jobs`，密钥配置在同层settings.json。投标备份包含已采纳内容及引用原件，不包含AI任务记录或密钥。新版本首次使用若无旧草稿，可从旧版投标备份恢复为副本；原版数据不要删除。

自动测试使用模拟DeepSeek响应，真实联网、账户模型权限、计费及真实样本效果尚待验证。可以先用一份脱敏短资料完成上述流程；确认采纳后仍须人工修改与专业审核。

官方接口参考（2026-10-05核对）：[Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)、[JSON Output](https://api-docs.deepseek.com/guides/json_mode/)、[模型列表及计价说明](https://api-docs.deepseek.com/quick_start/pricing/)。程序不写死费用单价。

## 尚未包含

扫描件OCR、PDF复杂版式保真解析、院标规则库、完整规范时效校核、自动计价、暗标匿名保证、动态页码目录、复杂合并表格、扫描证明附件自动装订、电子签章与平台提交。已核对稿只代表程序列出的人工确认完成，不代表满足某个招标项目全部条件。工程门类、地方要求和真实招标格式仍需用脱敏样本核定。

参考易标的资料→要求→章节→检查→导出流程，本轮为自行实现；未复制易标代码，未引入其 AGPL 组件；DeepSeek通过官方HTTP接口接入；PDF新增本机PdfPig 0.1.16依赖，许可和归属说明随包提供，不上传PDF原件。

## 本轮PDF集中验收

1. 用一份能选中文字的脱敏PDF导入，确认原文摘录中的否定、条件、表格文字和物理页序准确；尤其检查末页，不以印刷页码对照。双栏/复杂表格顺序需要人工核对。
2. 建立要求后点「定位来源摘录」应回到对应文字块；修改资料版本后，原正文不变，关联核对状态撤销。
3. 在AI辅助里仅选某一物理页，发送预览应只包含该页提取文字；取消不发请求。实际发送和计费仅在你确认后发生。
4. 导入扫描页或加密PDF，程序应保留原件并明确显示未识别/提取失败，不显示成已核对资料。

限制：单文件20MB、500页、全文60万字符、单页20万字形、3000摘录块，处理超过30秒会提示拆分或人工摘录；TXT50万字节。超限不静默保留前半份。详细边界见[BID_PDF_PARSING](BID_PDF_PARSING.md)。

## 本轮候选来源核对验收

1. 用一份脱敏资料生成要求候选，展开结果并点击「查看引用原文」，确认文件、摘录位置、否定条件一致。长资料应自动切换到对应摘录组。
2. 不采纳，先修改资料版本；重新打开AI辅助，应显示来源待重新核对，旧候选不能加入，原结果与人工正文仍在。
3. 点击「按此任务重新准备」，核对发送范围后确认生成，新候选可人工采纳。确认不覆盖原正文、不自动勾选专业复核。
4. 未联网时可反复预览和取消；实际确认发送才调用DeepSeek。取消或超时后手动重试，仍须重新确认，实际费用以账单为准。

本轮自动检查未调用真实DeepSeek。旧版目录、原件及数据保留；本轮升级到独立preview.4目录，不覆盖正在运行的旧程序。
