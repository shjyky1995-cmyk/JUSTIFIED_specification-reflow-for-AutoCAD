# A1 三栏测试模板 V1.0

用户授权自行制定本次测试排版，并要求后续可灵活调整。模板 ID：jsr-A1-three-column；版本 1.0.0，引用 jsr-note/1.0.0。格式遵循 [文字规则](TEXT_FORMAT_V1.md)，编号内联、两个半角空格分隔、无预留编号区。

## 本次明确采用的设计

- A1 横式，841×594 mm；沿用《新块.dwg》的三栏相对结构，将其图形尺寸按 100 归一为本次标准尺寸。这是新模板的设计选择，不是对旧图单位/打印比例的追认。
- Anchor 为说明区右上角，在模板内为 (0,0)。X 向右为正、Y 向上为正；栏按左到右，行按上到下填充。
- 每栏宽 230 mm，净间距 10 mm，高 511.91 mm；第三栏本次照常参与填充，不沿用样图第三栏留空的现状。
- 三栏首行基线统一设在上边界下方 6.2 mm；固定行距 7.2 mm；每栏设计 71 行，共 213 个视觉行槽。标题按实际换行数占槽，显式空行也消耗槽。
- 续页向右；同 Anchor 步长 (861,0) mm，841 mm 纸幅外另留 20 mm 页间隔。此为新定规则，不声称来自旧图的两页实测。
- framePolicy=none：本次只排文字，使用已有图框，不自动复制图框、标题栏或画辅助行格。
- 源图实体不动。本次旧图尺度测试若使用 unitScale=100，必须显式选择该值，字高450、行距720、栏宽23000、栏距1000；新建毫米测试图可显式用1。禁止从 INSUNITS=0 自动推导100。

## 检查与发布状态

首行字高名义上沿距栏顶 1.7 mm；末行基线为 -6.2-70×7.2=-510.2，距栏底 1.71 mm。三个栏不相交，均在页内；续页边界净隔20 mm。这些是数值几何检查，不是实际字体上下伸出、上下标或打印通过的证据。

此处71行是本次明确选定的测试容量，恰与旧图行格数一致，但新基线和行距均按项目规则重新制定，不是把旧图实测第一基线复制过来。实际字形外包边界仍须完整落在栏内；若不满足，修改模板版本，不能用公差掩盖可见越界。

草案文件在 standards/drafts；classification=draft、status=uncalibrated，正式读取器应拒绝发布。真实字体/特殊字符/打印验证完成后才按既有流程发布。A2/A3 后续可以同样制定独立模板，不要求找齐院标，不能冒称目前已经有可用配置。
