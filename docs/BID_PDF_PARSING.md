# 投标资料本地提取（T36）

实现和脚本在独立工作树 `artifacts/worktrees/t34-bid-workbench`；本根目录仅同步说明与工作线入口。

2026-10-05，用户明确批准“先本地文字型PDF、增加解析依赖；扫描件暂不OCR”。采用现有.NET 10工作进程 + PdfPig 0.1.16，Apache-2.0；不增加第二套运行时、云解析或CAD依赖。官方使用说明：[PdfPig](https://github.com/UglyToad/PdfPig)，固定版本：[NuGet 0.1.16](https://www.nuget.org/packages/PdfPig/0.1.16)。不使用容易混淆阅读顺序的 `page.Text`，采用官方 `ContentOrderTextExtractor`，仍由人工核对双栏和表格。

## 行为与边界

- 原件按SHA256保存，提取只读。PDF按物理页1开始定位，`PDF物理页 N / 文字块 M`；封面、空白页和扫描页都占页序，不映射成印刷页码。
- 文字层提取逐页保留；长页按换行优先分成不超过2万字符的块。文件20MB、500页、全文60万字符、单页20万字形、3000块上限；超限返回失败并保留原件，不把部分文字标为完整提取。工作进程处理超30秒由既有主进程停止，保留原件和失败提示。
- 没有文字的页明确列出，可能为扫描或空白；含图片页提示图片内容未识别。异常编码提示人工核对。图片/OCR、批注、表单值、内嵌附件、复杂阅读顺序不保证提取，界面逐份保留这些提示。提取成功不等于资料已人工核对。
- 加密/损坏/不支持字体或结构无法提取时不保存部分摘录，原件可打开或备份。暂不接收PDF密码，用户自行另存无密码文字型副本后重新导入。
- 资料摘录按20块分页显示，要求可定位到来源摘录。超过单项摘录限额的旧DOCX块不能截断建立要求，改为人工拆分。
- DeepSeek可选PDF物理页范围，保留原摘录索引。发送预览只含所选页提取文字；无正文页范围明确拒绝。单次4万字符限额不变，不自动截断；每次仍需人工预览确认。任务记录保留页范围，重开/重试/采纳仍按原范围验证引用。
- TXT完整逐行提取，支持UTF-8与带BOM的UTF-16，原行号包含空行；50万字节或3000块超限、错误编码均明确报告，不再静默只保留前5万字符。
- 修改资料类型、版本或补遗关联后，相关要求、证明资料和响应章节核对状态失效，正文和原件保留。没有明确影响目标的补遗保守要求整标复核；不作工程影响的自动判断。
