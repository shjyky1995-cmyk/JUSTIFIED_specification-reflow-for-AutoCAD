# EngiSpace「设计说明」PRD（评审稿）

版本：2026-09-27。本文定义**下一阶段桌面端**；已发布 CAD v0.1.0 的功能、验收与范围仍见根目录 `CAD_DesignNote_PRD_V1.0.md`。来源：[产品讨论](https://chatgpt.com/c/6ab7c1e5-a640-83ee-8970-02db6581d11c)、[Figma Make 初稿](https://www.figma.com/make/a5aAqGbX72atqBfZJTrqHW/工程设计应用首页UI设计?t=95q0L0mS9Cg5loNU-1)、用户 2026-09-27 补充决定及现有仓库；**后确认的业务规则优先于设计稿及旧 D0 假设**。Figma 账号连接有效，但 Make 接口只返回源码目录链接，浏览器会话读取失败；未直接核对当前画面，视觉细节须后续复核。

## 1. 目标与边界

各专业共用生产链路：**项目资料（可选）→选择专业→该专业参数（若有）→选择章节组合→调整当前说明正文→连续预览→导出 DOCX**。选择「结构」时展示结构参数；选择其他专业时**跳过所有结构专属字段**，直接进入模板/章节工作区并可生成。用户仍可在 Word/WPS 修改最终 DOCX，然后在 CAD 中手动选择该文件，用现有 `DSS` 落图。桌面端与 CAD 无同步、调用或额外交接文件。桌面端生成结构化文字；不负责 Word 视觉排版或 CAD 图幅“页数”。

应用首页保留「设计说明、可研报告、招标文件、项目管理、AI 工程助手」等产品入口，以及当前项目、最近工作和搜索的设计位置。**本阶段所有列出的专业都要能完成说明编制与导出；专业标准正文可后续补充**。设计说明以外的业务入口不展示虚假的可用操作。首页默认打开，进入设计说明后可返回首页。现有 Figma 曾以临时占位首页和直接进入新建页展示，不能把它当最终导航基线。

## 2. 用户流程与页面

| 状态 | 用户操作 | 系统行为 / 验收要点 |
| --- | --- | --- |
| 首页 | 打开或继续说明 | 最近说明可恢复；新建进入步骤 01；返回首页后状态不丢失 |
| 01 参数设置 | 选专业；可关联已有项目，或手填项目名称、编号、建设单位、地点；结构专业填写专属参数 | 关联项目带出四项且可核对；非结构专业跳过结构参数；切换/取消关联不悄悄覆盖已编辑内容 |
| 02A 模板选择 | 结构可选框架、水池、水池＋框架、钢结构或自定义组合；其他专业选择已有本专业组合或自定义组合 | 预设模板只是章节默认组合；自定义组合从**可用章节库**选取，不是空白文档；无已核实专业正文时不虚构规范文字 |
| 02B 章节工作区 | 添加、移除、拖动排序；新建当前说明专用章节；逐章改纯文本 | 左侧只列已选章节，统一「添加章节」入口分为标准章节/自定义章节；右侧正文自动保存，显示保存中/已保存/失败；不出现富文本工具栏 |
| 03 生成说明 | 看整份连续只读预览；重新配置；导出 Word | 预览顺序与导出一致；需要改正文返回 02；导出为可由现有解析器读回的 DOCX，不覆盖已有文件 |

从 02B 返回 02A 可重选模板；修改 01 专业参数时，先明确提示**当前章节副本及文字修改将重建**，用户确认后才执行。取消则保持原样。单章「恢复默认」只影响当前说明的该章。关闭、崩溃或重新打开后可恢复最后一次成功保存的说明；保存失败不能显示「已保存」。

## 3. 内容规则

- **项目与参数**：专业为建筑、结构、给排水、电气、暖通、其他，均可选、可编辑章节并导出。只有结构显示下述结构参数；其他专业直接进入章节组合，未来各专业参数另行扩展。结构基本参数含场地类别、抗震设防类别（甲/乙/丙/丁）、结构安全等级、地基基础设计等级；设计使用年限默认 50 年，不占常规输入位。水土腐蚀性为可粘贴长文本；材料/防腐选弱、中、强方案，并可选附加措施。抗震设防烈度只读，只有具备**经核验的地点映射数据**时自动给值，否则显示「待核定」，绝不猜值；数据调研见 [来源记录](SEISMIC_DATA_SOURCES.md)。
- **标准章节库与模板**：标准章节有稳定 ID、版本、专业、标题、正文模板和适用条件；预设模板记录有序章节 ID 清单。专业正文允许后续逐步补齐，框架阶段仅放经过确认的通用章节结构/脱敏演示文字。用户可输入当前说明正文以完成导出；软件不把占位文字当作正式工程结论。模板初选后仍可加、移、排序。自定义章节只属于当前说明，不回写标准库。
- **当前说明**：保存项目快照、专业参数、所选模板/标准版本、章节顺序和各章节**正文副本**。正文为纯文本，允许变量生成后的人工改写；更改本份正文不改标准。未解析的变量、缺必要参数、空章节等应明确定位，不能静默导出错误正文。
- **输出**：按当前顺序组成标题/章节/正文，预览与 DOCX 语义一致。DOCX 用 Word/WPS 可编辑，导出后由现有 `DocxDocumentParser` 读回检查；不写表格、图片、宏，也不静默覆盖用户编辑过的 DOCX。

## 4. 界面与状态

沿用 EngiSpace 首页/现有 CAD 窗口的浅灰白、冷静蓝、克制留白与清晰字体层级，界面文案以自然中文为主。顶部轻量三步导航；01 窄而易填，02B 用约 25–30% 目录与 70–75% 纯文本编辑区，03 用较窄白色文档面连续预览。窗口缩放与较长中文标签不能遮挡内容；错误与保存状态靠近操作位置。Figma 是布局和视觉初稿，交互须以本 PRD 为准。

## 5. 本阶段交付与延期项

先交付**所有专业可用的编制框架**：首页导航、本机项目/草稿数据、按专业显示参数、章节组合/编辑与自动保存、连续预览、DOCX 导出及与现有 CAD 的人工文件闭环。专业正文、完整标准模板和抗震地点数据可在后续内容阶段补齐，不阻断框架验收。复杂表格编辑、AI 校审、协同/云同步、CAD 实时连接、DWG 回写和富文本排版留待后续阶段。未来内容模型可扩展「文本块＋固定表格块」，当前**只实现文本块**，不预建空服务。

验收界限：框架阶段逐一检查六个专业均可选择、编辑、预览、导出；非结构专业从头到尾不出现结构专属字段；结构参数数据缺失时只提示未核定，不生成假值。专业规范文字的正确性在内容阶段另行验收。
