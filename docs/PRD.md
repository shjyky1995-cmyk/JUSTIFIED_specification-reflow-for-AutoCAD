## 1. 目标与边界

各专业共用生产链路：**项目资料（可选）→选择专业→该专业参数（若有）→选择章节组合→调整当前说明正文→连续预览→导出 DOCX**。选择「结构」时展示结构参数；选择其他专业时**跳过所有结构专属字段**，直接进入模板/章节工作区并可生成。**本阶段桌面端的交付终点是可编辑的 DOCX 文件**。用户可在 Word/WPS 修改并保存最终 DOCX，再自行到 CAD 中用现有 `DSS` 选择该文件落图；CAD 操作不属于桌面端流程或本阶段验收前置条件。桌面端与 CAD 无同步、调用或额外交接文件。桌面端生成结构化文字；不负责 Word 视觉排版或 CAD 图幅“页数”。

应用首页保留「设计说明、可研报告、投标文件、项目管理、AI 工程助手」等产品入口，以及当前项目、最近工作和搜索的设计位置。**本阶段所有列出的专业都要能完成说明编制与导出；专业标准正文可后续补充**。设计说明以外的业务入口不展示虚假的可用操作。首页默认打开，进入设计说明后可返回首页。现有 Figma 曾以临时占位首页和直接进入新建页展示，不能把它当最终导航基线。

## 2. 用户流程与页面

| 状态 | 用户操作 | 系统行为 / 验收要点 |
| --- | --- | --- |
| 首页 | 打开或继续说明 | 最近说明可恢复；新建进入步骤 01；返回首页后状态不丢失 |
| 01 参数设置 | 选专业；可关联已有项目，或手填项目名称、编号、建设单位、地点；结构专业填写专属参数 | 关联项目带出四项且可核对；非结构专业跳过结构参数；切换/取消关联不悄悄覆盖已编辑内容 |
| 02A 模板选择 | 结构可选框架、水池、水池＋框架、钢结构或自定义组合；其他专业选择已有本专业组合或自定义组合 | 选择预设模板后，按该模板绑定的资料版本自动装配章节和正文初稿，不要求用户再进资料库挑条款；无可靠来源的模板显示缺口，不能虚构文字 |
| 02B 章节工作区 | 已装配的初稿直接呈现；填写工程值、核对来源和适用性，必要时删改、增章和排序 | 左侧只列已选章节；右侧正文自动保存，显示保存中/已保存/失败；资料来源供核对，不是必经的选材步骤 |
| 03 生成说明 | 看整份连续只读预览；重新配置；导出 Word | 预览顺序与导出一致；需要改正文返回 02；导出为可由现有解析器读回的 DOCX，不覆盖已有文件 |

从 02B 返回 02A 可重选模板；修改 01 专业参数时，先明确提示**当前章节副本及文字修改将重建**，用户确认后才执行。取消则保持原样。单章「恢复默认」只影响当前说明的该章。关闭、崩溃或重新打开后可恢复最后一次成功保存的说明；保存失败不能显示「已保存」。

## 3. 内容规则

- **项目与参数**：专业为建筑、结构、给排水、电气、暖通、其他，均可选、可编辑章节并导出。只有结构显示下述结构参数；其他专业直接进入章节组合，未来各专业参数另行扩展。结构基本参数含场地类别、抗震设防类别（甲/乙/丙/丁）、结构安全等级、地基基础设计等级；设计使用年限默认 50 年，不占常规输入位。水土腐蚀性为可粘贴长文本；材料/防腐选弱、中、强方案，并可选附加措施。抗震设防烈度由用户按工程所在地人工选择：6度（0.05g）、7度（0.10g/0.15g）、8度（0.20g/0.30g）、9度（0.40g）；未选择或旧草稿的「待核定」值在导出前明确阻断。界面不按地点自动猜值；“7度半/8度半”在正式说明中写成 7度（0.15g）/8度（0.30g）。对应关系见 [GB 55002-2021 第 2.2.2 条公开文本](https://sjw.nanjing.gov.cn/gdzsj/zcfg/gfxwj/202402/P020240228543138060438.pdf)；地点映射数据的后续调研见 [来源记录](SEISMIC_DATA_SOURCES.md)。
- **标准章节库与模板**：内容库放在本项目独立的 `content-library/` 文件夹；私有 `private/` 保存旧工程候选数据，不进入公开仓库，也不复制到 C 盘。标准章节有稳定 ID、版本、专业、标题、正文模板和适用条件；预设模板绑定来源版本和自动装配规则。选模板后直接生成对应章节与正文初稿，用户只需核对、填写工程数值和按需修改；资料库挑条款仅可作为开发核对手段，不属于成品流程。候选正文未经专业核定时，预览和 DOCX 都标明待核定，不冒充正式工程结论。无可靠来源的模板只给空框架并显示缺口。
- **当前说明**：保存项目快照、专业参数、所选模板/标准版本、章节顺序和各章节**正文副本**。正文为纯文本，允许变量生成后的人工改写；更改本份正文不改标准。未解析的变量、缺必要参数、空章节等应明确定位，不能静默导出错误正文。
- **输出**：按当前顺序组成标题/章节/正文，预览与 DOCX 语义一致。DOCX 用 Word/WPS 可编辑，不静默覆盖用户编辑过的文件。纯文本说明由现有 `DocxDocumentParser` 读回检查。2026-09-29 用户要求先把水池说明做到接近原件，B 阶段水池基准因此增加来源顺序的正文块和可编辑表格；含表格文件由桌面工作进程做 OOXML 结构读回，并明示当前 CAD 插件不支持表格导入。图片、宏与 CAD 表格排版仍不在本次范围内。

## 4. 界面与状态

沿用 EngiSpace 首页/现有 CAD 窗口的浅灰白、冷静蓝、克制留白与清晰字体层级，界面文案以自然中文为主。**产品图标唯一原稿为 `branding/product-icon.png`**，桌面和 CAD 都读取它；更换流程见同目录 README。首页按设计稿呈现顶部品牌、搜索、三张文档入口加两张横向功能入口、当前项目和最近工作；本阶段只让「设计说明」入口进入真实业务流程。顶部轻量三步导航；01 窄而易填，02B 用 280px 目录和剩余宽度的纯文本编辑区，03 用居中的白色文档面连续预览。01 可先进入模板与正文编制，缺少必要参数在 03 导出前集中定位并阻断。窗口缩放与较长中文标签不能遮挡内容；错误与保存状态靠近操作位置。Figma 是布局和视觉初稿，交互须以本 PRD 为准。

## 5. 本阶段交付与延期项

先交付**所有专业可用的编制框架**：首页导航、本机项目/草稿数据、按专业显示参数、章节组合/编辑与自动保存、连续预览和 DOCX 导出。专业正文、完整标准模板和抗震地点数据可在后续内容阶段补齐，不阻断框架验收。B 阶段先为水池基准实现「文本块＋固定表格块」及表格单元格编辑，以复现原说明的章序和内容位置；其他专业表格、AI 校审、协同/云同步、CAD 实时连接、DWG 回写和富文本排版留待后续阶段。

验收界限：框架阶段逐一检查六个专业均可选择、编辑、预览、导出；非结构专业从头到尾不出现结构专属字段；结构参数或烈度缺失时阻断导出，不生成假值。专业规范文字的正确性在内容阶段另行验收。
