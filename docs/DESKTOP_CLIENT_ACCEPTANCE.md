# T31/T32 客户端集中试用

本轮人工检查按用户要求集中进行；以下均为待验收项。

1. 先关闭旧窗口。免安装入口：项目根 `测试文件/设计说明客户端试用/EngiSpace-0.2.0-preview.2-内容核对版/client/EngiSpace.exe`。也可完整解压同名 ZIP，运行 `DesktopSetup.exe` 安装后从桌面快捷方式打开。
2. 新建结构说明，留空工程名、烈度或其他参数，选水池/框架模板，直接生成并点击「导出 Word 草稿」。应生成可打开的 DOCX，缺项显示待填写，文字和表格仍保留。工程资料区域不再并列三套模板字段，标高、地区、地下水情况各有明确名称。
3. 在章节里修改一句文字、一个表格值或章标题；关闭并重新打开，应保留最后修改。参数修改后回章节应保留正文；可以撤销、重做、复制草稿。
4. 右上设置导出全部备份，再从备份恢复；首页应新增副本，原稿不被覆盖。长章节滚动、窗口缩放、Word/WPS分页与表格编辑也请一并检查。
5. 方便时检查安装、升级、回退及卸载。详见 `DESKTOP_CLIENT_GUIDE.md`；卸载应保留草稿。不要使用未核定的旧工程候选文字作为正式工程结论。

## T32追加观察（仍待人工验收）

- 模板页应显示来源、章节/段落/表格数量；钢结构/其他明确空框架，给排水提示当前工艺总图范围。
- 生成说明后点击「去填写参数」应定位01输入；适用条件/旧工程事实项定位02B相应段落/表格。同一缺项只列一次，展开「出现多处」可逐处定位。
- 打开「查看正文来源与规范引用」，搜索编号或章节并定位原处；改一处规范编号，重新预览后旧编号应消失（其他位置仍有引用则保留）、新编号出现。来源和识别编号不表示已核定有效版本。

## T33反馈修正观察（2026-10-06，待下一轮试用）

- 02B 正文应为干净段落：无 `C00xx` 编号、来源行、「待核定/规范引用待核对」标签；点「修改文字」就地编辑并保存。
- 水泥品种、限制膨胀率、环境类别、蓄水类防水等级等稳定参数应显示原稿默认值（如普通硅酸盐水泥、防水等级一级），不再逐项待填写；要改直接在正文中修改文字。
- 01 结构参数应出现「活荷载参数表」：选模板后带入池顶 5.0、不上人屋面 0.5、太阳能 2.0、楼梯 3.5，可改值、增删行；02B 对应表格和导出 DOCX 应同步。
- 设计依据章节应为标准清单行：可「从规范库添加」或手动添加编号，可「移除本段」删除，导出 DOCX 应反映增删。
- 03 不再有「查看正文来源与规范引用」入口；导出成功后只显示「导出成功」与「打开这份 DOCX」，点击后应用应打开生成的 Word 文件。
