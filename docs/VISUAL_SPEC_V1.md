# 双端界面视觉规范 V1（2026-09-25）

本规范定义 CAD 选择窗口与安装向导共用的视觉语言：颜色、字体、间距、控件状态、错误与进度提示。桌面端（未来的独立程序）上线时先对照本规范，再按桌面场景补尺寸细节。规范只约束**程序界面**，不改变落图 DBText 的字体、院标或打印字形。

## 字体

- 统一使用 **Noto Sans SC**（SIL OFL 1.1），从安装包内 `Contents/Windows/fonts/NotoSansSC-VF.ttf` 用私有字体集合加载，不要求用户电脑预装；字体 SHA256 固定为 `763146584CF0710223441356B4395E279021B0806C196614377A7A0174AE074A`，与 `docs/UI_TYPOGRAPHY.md` 一致。
- 像素字号级差（CAD 紧凑窗口实测值）：窗口标题 22–23、区块标题 17–18、正文与输入 14–16、辅助说明 13–14。正文行高不小于 1.4 倍，中文不斜体、不加下划线。

## 颜色

| 用途 | 色值 |
| --- | --- |
| 主文字 Ink | `#1A2233` |
| 次要文字 Muted | `#636F85` |
| 主操作蓝 Blue | `#1365E6` |
| 分隔线/边框 Line | `#D2DCEB` |
| 背景 | `#FFFFFF` |
| 通过/成功 Good | `#16844A` |
| 阻断/失败 Bad | `#C83028` |
| 卡片选中底 | `#F2F8FF` |

主操作一屏一个（蓝色实底白字），取消/次操作为白底灰字；不用超过一种主色。

## 间距与结构

- 页边距 16–28 px；卡片/输入框高度 44–64 px；区块之间用 1 px 分隔线而非重阴影。
- 两步以上流程必须在页脚显示步骤指示（如“① 欢迎 → ② 环境检查 → ③ 安装 → ④ 完成”），当前步骤高亮。
- 图标仅作辅助，必须配短文字；不只用图标表达含义。

## 控件状态

- 选中：主蓝 2 px 边框 + 浅蓝底 + 右上角蓝底白勾。
- 不可用/缺资产：Muted 灰，点击后在状态行给出原因，不静默跳过。
- 禁用主操作时必须同时显示原因（状态行文字），不留无解释的灰按钮。

## 错误与进度

- 阻断性错误：红字 `#C83028` + 一句可执行的处理办法；不使用弹窗轰炸。
- 进行中：确定性步骤用进度条 + 日志行（每行一句“已完成什么”）；不编造预计秒数。
- 失败：保留已完成的现场，主操作变“重试”，日志写明失败原因；不把异常栈抛给用户。
- 完成页必须写清下一步（重启 CAD、`DN_DIAG`、`DSS`）与回滚方法。

## 已落地情况

- CAD 选择窗口（`NotePickerForm`）与安装/卸载向导（`SetupWizard`）均按本规范实现；安装向导的界面字体同样来自随包 Noto Sans SC，缺失时回退系统微软雅黑，不因此阻断安装。
- 2026-09-25 用户验收后调整：CAD 选择窗 780×480 → **700×400**，图幅卡片缩为原来的 3/4（126×94，面积为原来的 60%），整体更紧凑；窗口圆角（Region 半径 10）与卡片/输入框圆角（8）落地，字级不变（标题 20、区块 14、正文/输入 14、卡片主字 16、辅助 11–12）。紧凑原则：留白服从字号，卡片不小于内容最小可读尺寸的 3/4。
- 竖向对齐网格（用户 2026-09-25 强调“横平竖直”）：所有内容行共用左缘 x=130（区块标题 x=22）与右缘 x=670；卡片等宽 126、间距 12；比例输入框与档位按钮同基线；页脚主按钮与取消按钮右缘对齐。禁止出现左缘不齐的行。
- 圆角绘制纪律：圆角控件必须同时屏蔽 `OnPaintBackground` 并用 `GraphicsPath` 填充圆角区域，否则默认直角底色会在圆角外露出白色斑块（2026-09-25 修复）。
- 选中态不使用浅色填充（与白色窗体在圆角处会有色差斑）；用 2px 主蓝边框 + 右上角蓝底白勾表示。
- 2026-09-25 用户验收后调整：安装页文案重写（只保留“是什么、先退出 CAD、支持环境”三句），删去耗时/联网/字体/待验/卸载提示；环境不满足时对 .NET Framework 4.8 提供一键下载静默安装并自动复检。正式命令简化为 **DSS**。程序图标由 note-logo 生成多尺寸 `app.ico`，用于“应用和功能”条目与安装器窗口。
- 模板几何（2026-09-25 用户要求）：锚点改为**图面左上角**；说明栏组在整页内**横向居中**（左右边距相等）；顶部预留 60mm 图框与标题栏空间；页间距 = 页宽（紧贴，消除原来的 20mm 间隙）。模板版本升 1.1.0，`PublishedPackageContentsTests` 用数值断言锁定这些语义。
- 程序图标：项目 logo（三段式图形）已制成多尺寸 `app.ico` 编译进安装器，“应用和功能”条目、安装器窗口标题栏与任务栏均显示该图标；CAD 选择窗无标题栏，窗内左上角展示同一 logo。
- 视觉稿与实现的关系：`docs/assets/cad-note-picker-concept-v2.png` 是设计稿；真实外观以 CAD 宿主截图为准（最新离线预览 `docs/assets/cad-note-picker-v5-compact-rounded.png`），规范随实现演进而更新，不允许实现长期偏离规范。
