# A1 / A2 / A3 项目院标模板 V1.0

本项目正在制定完整院标，用户不需要提供一套既有完整院标。支持多套机构或个人标准独立配置、选择和修改；格式与图幅模板是独立的配置入口。当前这套标准为 jsr-note/1.0.0，可作为新标准的起点，不是所有人的强制唯一标准。

## 共同规则

三种图幅均为横式，引用同一文字标准：tssdeng.shx + tssdchn.shx，字高4.5 mm、宽度因子0.75、倾角0°、行距7.2 mm。纸幅变小只改变栏宽、栏高和容量，不缩小字体、不压缩行距；内容多时自然换栏、续页。编号内联，用两个半角空格分隔，首行与续行从栏左起排。

本套标准规定 A1/A2 三栏、A3 两栏。三者栏间距10 mm，首基线均在栏顶下方6.2 mm；先从左到右逐栏填满，每栏从上到下。续页向右、纸幅间隔20 mm，framePolicy=none，只排文字。单位转换必须显式配置。

## 多套标准的独立配置入口

- 个人/机构新标准使用独立standardId与version，不能修改另一套标准来冒充个人设置；复制当前规则后可以独立修改字体、字高、行距等参数。
- 模板使用独立templateId与version，通过standardRef精确引用所属标准版本；同一标准可以拥有多图幅、多布局模板，同一图幅也可以存在多个标准的模板。
- 标准和兼容模板在工程设置时明确选定并记住，日常生成直接沿用。不能每次让设计人员重选，也不能按图幅名、文件顺序或当前DWG默认样式偷偷换一套；版本引用不匹配须拒绝。
- 已发布版本不可原地覆盖，修改后发布新版本并重新校验；旧任务仍能定位原标准。引擎读取配置，不写死三栏、两栏或本表容量；将来其他个人标准可以有不同布局，本次栏数约束属于当前这一套标准。
- 继续使用已有IStandardProvider / ILayoutTemplateProvider和标准/模板契约，不新增空服务或可视化编辑器。配置入口已经有数据契约基础。正式界面是记住工程设置后的一键生成；当前 DN_NOTE 的多步提问只是开发核对，不能称为已经交付的操作界面。

## 文件与验证状态

草案位于 standards/drafts/jsr-note-1.0.0.json 和三个 jsr-A*-1.0.0.json，全部classification=draft；模板status=uncalibrated。本次已检查尺寸、栏间距、首末基线、页面包含关系、相邻页间隔及标准引用；实际字形、上下标外包边界、图签适配和打印尚需验证。制定完整规则与验证这些规则是两个阶段，不能再以“没有完整院标”阻止制定，也不能用规则文件替代实测验收。
