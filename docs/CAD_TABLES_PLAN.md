# CAD 表格写入增量阶段（T28）

日期：2026-09-29。状态：用户已确认“可以开始实施”；共享协议方案获准，候选已实现并通过自动检查，真实 CAD/打印待验收。

## 目标与依据

用户说明设计说明中表格占比很大，要求 CAD 支持表格文字与线条，字体、字号、行高对应 CAD 设置，表宽限制在说明栏内。新增独立 CAD 增量阶段，不改写 v0.1.0 已发布的表格拒绝规则，不改变桌面与 CAD 经最终 DOCX 人工衔接的方式。

已检查：现有 DocxDocumentParser 遇到 Table 会阻断；Block 仅含标题、段落和空行；现有布局协议只承载文字行。T27 分支已有可编辑表格 DOCX，但其 OOXML 检查不等于 CAD 导入通过。T28 不依赖将未验收桌面代码合入 CAD 分支。

## 推荐排版规则（供本次确认）

1. 保留 DOCX 中正文、表格、正文的先后顺序。单元格文字输出 DBText，表格边线输出 LINE，用户可在 CAD 中编辑；继续使用 DSS 选文件、图幅、单位、点位置。
2. 字体、字号、宽度因子采用本次说明生成所选的 CAD 标准，不按 Word 字体或临时当前文字样式猜测。真实字体测量同时用于表格换行，不能靠字符个数估宽，也不缩小字号塞入单元格。
3. “间距跟页间距一样”暂按表内文字沿用正文行距理解：单行单元格占一个基础行高，多行单元格按同一行距增加；整行高度由最高单元格决定并对齐正文行槽。单元格上下、左右留白及表前后间隔写入版本化标准，最终数值待制定与验证，不写死在程序中。续页的页间距沿用原模板。
4. 按 DOCX 表格网格的列宽比例分配当前说明栏宽；总宽不超过当前栏的可用宽度，留白计入列宽。下一栏宽度不同时重新测量排版。缺少有效列宽时明确诊断，不静默猜测或截断内容。实施核对发现桌面导出的矩形表格明确使用 tcW=auto 且不含网格；候选标准显式配置 equal-columns-with-warning，允许这类无合并矩形表等宽排布并发出 W_TABLE_AUTO_WIDTH，导入沿用有警告确认。其他缺失/非法列宽仍阻断。
5. 首批覆盖普通矩形表格、横向及纵向合并单元格、多段单元格与多行文字。保留可见边框的位置，包括横线和竖线；无边框不强制补成全网格。边框统一使用标准配置的 CAD 线型、线宽，不复刻 Word 阴影、底色或装饰样式。共享边只画一次，合并内部不穿线。
6. 一栏剩余高度不足时整行移到下一栏，纵向合并覆盖的行作为整体移动。表格可按完整行组跨栏、跨页；Word 标记的表头在续栏重复。任一行组加必要表头仍超过空栏高度，阻断并给出表格/行位置，不裁切、漏字或无限续页。嵌套表格、斜线、竖排文字及表内图片等暂不支持，必须定位阻断。
7. 表格和正文共同参与资源限额、进度、取消、报告及同一落图事务；失败/取消零新增，一次撤销同时去掉本次文字和线条。单位比例、点位、UCS 坐标转换对两者一致。

## 方案及影响

推荐继续扩展现有解析→排版→渲染链路。像原来传递“一段文字”，现在还需传递“一张表的行列与边框”，并让排版结果包含线段坐标；这就是本次共享协议变更的原因。替代方案是 CAD 原生 TABLE 对象，但不符合用户指定的线条输出，本次不推荐。

- Contracts / DocumentCore / schemas：新增表格块、行列、单元格合并与边框语义及来源定位；布局增加自有线段几何、表格占位及统计。协议采用显式新版，旧文档继续可读，旧版消费者对新版明确拒绝；具体版本与迁移测试在实现时登记，不让旧消费者静默忽略表格。
- DocxAdapter：解析表格网格、合并、表头、边框继承与单元格内容；不把表格拆成无结构段落。
- Standards：增加版本化表格样式；旧标准处理必须明确，缺生产参数时给出可操作诊断，不套用测试默认值。
- LayoutEngine：测量单元格、分配列宽、对齐行高、处理合并及跨栏续排，产出最终 DBText 位置和 LINE 端点。
- AutoCadAdapter：仅消费已排好的文字与线段，统一坐标转换及事务写入；不重新解析或换行。
- Application / PluginHost：资源限额、预检、提示和报告覆盖表格与线条。DSS 操作方式不增加一步。
- 不增加技术栈、依赖方向或桌面→CAD 接口。桌面端读取共享协议和 W_TABLE_CAD_UNSUPPORTED 提示的调整，在 CAD 候选通过后单独核对版本兼容，不提前取消警告。

## 实施与验收

确认方案后，在 T28 分支连续完成协议/解析、布局、落图和候选安装包，不把内部小步变成用户确认关卡。仅使用脱敏样本入库。

| 检查 | 通过标准 |
| --- | --- |
| 解析/协议 | 正文与表格顺序、空单元格、多段文字、合并与边框往返一致；新版与旧版兼容策略明确；不支持内容有位置且零落图 |
| 核心排版 | 不同栏宽、长中文/数字/上下标、合并行组、重复表头、恰好满栏、跨页、超高与超窄边界；不越界、不重叠、不漏字，不产生空尾页 |
| 输出与回归 | 单位比例、UCS、非零点位、共享边去重、文本+线条限额与取消；纯文本旧样本不退化；net8.0/net48 检查和插件构建通过 |
| 真实 CAD | 用户方便时用候选包 DSS 导入脱敏样本：A1/A2/A3 表宽在栏内、字体字号一致、线条与文字对齐、合并正确、续栏正确、一次撤销完整；图面/打印结果与自动检查分开登记 |

交付前准备简短操作步骤、样本与自动报告。宿主未验证保持待验收；不把旧版签收视为新表格功能签收。阶段验收后才合并、打标签和推送发布。
