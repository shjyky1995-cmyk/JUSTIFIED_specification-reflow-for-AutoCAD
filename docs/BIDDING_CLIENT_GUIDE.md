# 投标框架移植版试用说明

版本0.4.0-bid-preview.1；T38，本机候选，待用户验收。此版本直接移植OpenBidKit / 易标框架，适配EngiSpace视觉；原作者mark / yibiaoai与AGPL-3.0-only许可保留，包内附对应源码。

## 打开与选文件

1. 整包保留在G盘，双击client/EngiSpace.exe，首页点击「勘察设计投标」。软件会打开独立投标窗口，原工作台暂时隐藏。
2. 进入原版「内容生成」的第一步「选择标书」，点击「选择招标文件」或「上传」。先导入一份脱敏TXT或DOCX，确认正文显示完整，特别是“不接受”等条件。
3. 按原框架继续：选择标书→生成设置→招标分析→目录→全局事实→内容生成→扩写。模板设置、知识库及标书检查保留原版能力及其未完成项。
4. 点击左上角「返回工作台」关闭投标窗口，主工作台会恢复。重新进入后核对已导入资料和已保存目录仍在。

本版先保留原框架内容，不代表已经完善勘察设计专用目录和专业要求。原版处于开发中的入口仍受原限制；不要把候选内容当成经过专业核定的正式标书。

## AI与联网

到「设置」选择并配置你自己的AI服务和密钥；原作者官方账户、自动更新、许可检查等服务被关闭。上传招标文件与本地解析无需AI密钥；本地解析失败时查看原版提示，扫描件识别按你主动配置的解析服务处理。

统计与Agent失败诊断只写本机，不向原作者服务器上传。失败诊断继续使用原版密钥脱敏。你主动运行AI或解析API时会按原流程发送资料到所配置服务并可能计费。本版沿用原框架发送流程，旧版逐次发送预览不自动适用于新模块；先用脱敏文件测试。

密钥配置由新模块独立保存，不自动读取旧版DeepSeek设置。不要把密钥写入截图、反馈或公开源码。

## 数据与旧稿

新模块资料、SQLite数据库、配置、缓存与统计在包根portable-data/data/bidding-framework。使用「重置」前先备份该目录；关窗退出后再复制整目录。不要只复制一个SQLite文件或只移动exe。

首页「继续旧版投标草稿」保留原JSON编制流程，操作见BIDDING_LEGACY_CLIENT_GUIDE.md。本包初次运行为空；旧preview.4包及原portable-data保留原位，没有自动把旧投标稿转入新SQLite。若要继续旧稿，可在原版备份后从新包旧版入口恢复为副本。

设计说明继续使用原来的专用试用入口，由另一Agent维护。本包不附私有说明正文，不修改设计说明或CAD数据。

## 本轮集中检查

- 首页打开新框架，直接选择文件、取消选择、导入脱敏TXT/DOCX，确认无找不到文件入口的问题。
- 退出再进入，资料/已保存目录保留；退出投标后恢复工作台，旧版入口能打开。
- 选导出模板，导出DOCX后用Word/WPS打开，检查章节、文字、表格可编辑；真实分页、字体及长表仍待人工验收。
- 配置自己的AI服务，以脱敏短资料完成一次分析/目录/正文，核对发送范围和效果。真实AI/API/费用尚未由Agent测试。

异常反馈「哪一步＋完整提示文字＋资料格式」，可附脱敏截图。原包先保留以便回退。
