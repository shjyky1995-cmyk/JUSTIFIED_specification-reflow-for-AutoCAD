# CAD 表格试用（T28）

本包为 0.2.0-table-preview.1 候选，AutoCAD 2021，尚未完成真实图面/打印验收。旧版 v0.1.0 保留。

## 安装与操作

1. 保存当前图纸并退出 AutoCAD。将 `测试文件/CAD表格试用` 中的候选 ZIP 完整解压到一个新文件夹，双击其中 `Setup.exe` 安装/升级。不要在压缩包内直接运行。
2. 打开 AutoCAD 2021 的空白模型空间，输入 `DSS`，选择同目录的 `表格试用样本.docx`，先选 A3 并核对单位比例，再点一次位置。
3. 看普通表格、横向合并、纵向合并和长表：文字应与正文同字体、同字号，表宽不超过栏宽，合并处无线条穿过文字，长表按整行续栏并重复表头。
4. 点选文字应是单行文字（DBText），点选边框应是直线（LINE）。输入一次 `U`，本次全部文字和线条应一起消失。再次导入，按需试 A1、A2 和自己的最终 DOCX。
5. 自动列宽文档可能提示 W_TABLE_AUTO_WIDTH：当前标准明确采用等宽，不等宽需求请在 Word/WPS 设置列宽后保存。仅这类有警告情况会沿用现有确认步骤；普通文件不多问。
6. 方便时打印或导出 PDF 核对表线与字号。发生问题，请反馈图幅、单位比例、问题位置及命令行提示；可提供截图，不必重做全部检查。

通过标准：没有漏字、越栏、文字碰线或合并穿线；续栏顺序正确；取消/报错无半套对象，一次撤销完整。自动检查只证明核心逻辑，不代替真实字体与打印效果。

## 已知边界与回退

- 支持普通矩形表格、横向/纵向合并、多段文字、上下标、直接边框及普通表格样式的整体边框继承。
- 条件样式边框、嵌套表格、斜线、竖排、浮动定位、表内图片/公式等会定位阻断。条件边框可先在 Word/WPS 直接应用到单元格；不支持内容不能静默丢弃。
- 单行组连同表头超过完整栏高时要求拆分源表；不缩小文字或裁切。缺少有效列宽且不是明确自动列宽的矩形表会提示补齐。
- 候选只改变本次新生成对象，不更新旧图内说明；桌面端既有“CAD 暂不支持表格”提示尚未随本候选发布更新。
- 回退时退出 AutoCAD，用原 v0.1.0 发布包的 Setup.exe 恢复安装；保留原 DWG 和 DOCX。旧版仍不能导入表格。不要把本候选覆盖到公开正式发布。
