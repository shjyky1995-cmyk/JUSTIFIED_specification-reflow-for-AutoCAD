## 你在 AutoCAD 中做

1. 打开 AutoCAD 2021，使用“新建”检查是否弹出新建图纸窗口，再新建**空白测试图**。若再次只出现命令提示，请先输入 `~` 打开模板窗口，并记录此会话中 `FILEDIA` 命令显示的当前值。输入 `DN_DIAG`，应看到 `DN_DIAG_OK`。如果出现正常的插件加载提示，按本机既有授权流程处理；不要调低安全设置。
2. 输入 `DN_NOTE`。Word 文件选 `artifacts/t14-share/20260924-fix-43fa507/sample.docx`，图幅选 A2。确认没有模板目录或版本选择，并拖动页眉验证窗口能移动。
3. 仅在确认测试图是 **1 图形单位 = 1 mm** 时，单位比例填 `1`。否则按实际图纸单位填写，未知就先停下核对。
4. 点击“在图纸中点位置”，在空白处点一次。成功时命令行出现 `DN_NOTE_OK`。需要分段耗时时，先在 CAD 命令行输入 `(setenv "DN_NOTE_TRACE" "1")` 再执行 `DN_NOTE`，F2 里即可看到 `DN_NOTE_TIMING_MS` 整行；日常使用不设该变量，命令行只保留结果一行。
5. 再执行 `DN_NOTE`，确认上次选项预填但可改，改选 A1 或 A3 后在另一处点位，检查旧说明仍保留。第三次打开窗口点击取消，不应新增文字。
6. 放大查看分栏、上下标 `N/mm²`、`m³` / `10⁻⁴` 和钢筋符号，确认均没有问号；测试图可用一次 `U` 撤销最后一次新增。

请回传：选择窗口截图（新版为 780×480 圆角窗口）、`DN_NOTE_TIMING_MS` 整行（需先设 `DN_NOTE_TRACE=1`）、是否看到 `DN_NOTE_OK`、异常位置放大图和错误命令行。窗口高 DPI、键盘 Tab/Enter/Esc、点位取消也请顺手观察。打印、断网与专业审查尚不由这次测试自动通过。
