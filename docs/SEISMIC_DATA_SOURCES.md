# 抗震设防数据来源预研（2026-09-27）

结论：**不把 GitHub 上的零散烈度表直接作为生产值**。先做地点、来源版本、核定状态的字段与「待核定」显示；内容阶段再接入可追溯数据。省、市或县名称不能代替具体项目位置与特殊工程的专业核定。

| 路线 | 已核对的信息 | 建议 |
| --- | --- | --- |
| 官方标准 | [国家标准平台](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=EC0585F90CA21ABE02826394F266B623)显示 GB 18306-2015 现行；[2026 年公告](https://openstd.samr.gov.cn/bzgk/std/nd?no=2683)提示有修改单 | 作为权威基准，后续记录版本及修改单；核对文本/许可后再整理结构化表 |
| 官方查询 | [白银区地震局 2026 年答复](https://www.baiyinqu.gov.cn/XZJDBMDW/bmdw/qdzj/fdzdgknr/zczxwdk/art/2026/art_e12cc71e3e1041739e9e178d8ceb3a33.html)指向中国地震灾害防御中心的 `gb18306.net` 查询服务 | 优先联系/核对官方接口的开放范围、离线许可、覆盖与更新方式；未获允许时仅供人工核查，不抓取成库 |
| 开源仓库 | 使用 GitHub 代码搜索检索 GB18306、抗震设防烈度，发现相关代码和零散表述，未核实可直接用于全国生产查询的完整数据、来源、更新机制与再分发许可 | 仅作为线索/实现参考；逐条回溯官方标准，不直接复制作为工程结论 |
| 用户提供资料 | 院内已批准的规范摘录或查询结果可由用户后期提供 | 建成带来源、适用区域、版本、审定人/日期的可导入数据包；差异与未覆盖地点提示核定 |

建议顺序：官方数据/许可核对 → 小范围脱敏样本复核 → 版本化导入 → 覆盖率与更新检查。若拿不到可合法离线使用的数据，保留只读「待核定」和外部查询指引，由设计人员输入经核定的项目参数；绝不按模糊地名自动猜烈度。
