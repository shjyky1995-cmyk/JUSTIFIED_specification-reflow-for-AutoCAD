# 设计说明客户端试用说明

本版为待验收的 Windows 64 位离线客户端，交付到可编辑 DOCX。正式专业内容、工程条件与规范引用由设计人员核定。

## 安装与启动

将候选 ZIP 完整解压到一个文件夹，双击 `DesktopSetup.exe`，点击「安装 / 升级」。安装成功后使用桌面「EngiSpace 设计说明」快捷方式。安装到当前用户，不需要管理员权限、Node.js、.NET SDK 或 CAD；Windows 需具备 .NET Framework 4.8（安装器使用，与既有 CAD 安装器一致）。

可先免安装试用：双击解压目录 `client/EngiSpace.exe`。这也不依赖项目目录、开发环境或联网。旧试用脚本仍可继续使用；请先关闭旧窗口，程序会防止同时打开多个实例。

标为「本机资料版」的包包含本机旧工程候选正文，仅供当前试用，不公开上传。通用包不含这些正文，可在「设置与备份」中选择本机资料库目录的 `catalog.json`；`source-layouts.json` 应在同一目录。无资料时可使用自定义章节编制。

## 编制与导出

1. 首页点击「设计说明」，选择六专业之一。只有结构显示结构参数。
2. 填写已有资料；参数和烈度可留空，先选模板进入章节。选定模板后，01 只补充该模板所需的工程字段；池顶、屋面、地下水结论分别有明确名称。
3. 修改章节正文和表格；可调整章序、添加自定义章节、撤销、重做和手动保存。右侧长章节可向下滚到底。
4. 点击「生成说明」，查看连续预览；待完善项可直接定位输入或正文，「查看正文来源与规范引用」可搜索当前文字中的编号并定位。随后点击「导出 Word 草稿」。未填参数保留「待填写」标记，未核定内容标为待完善草稿。无需逐项填齐或勾选适用性即可导出。
5. 全部参数与适用条件核对后，可使用「导出已核对说明」。这只代表本份说明已由编制人员核对，旧资料不会因此成为已批准的全局标准。
6. 在 Word/WPS 打开并修改导出的 DOCX。已有文件不会被覆盖，需要另取文件名。需要导入 CAD 时自行运行 CAD 插件 `DSS`。

没有任何正文、损坏段落或非法表格结构仍会报错，避免生成丢内容的文件。钢结构和其他专业尚无可靠主体原稿，使用空框架与自定义文字；不可将空框架冒充已完整填充的专业内容。

## 保存、备份与恢复

- 日常约一秒自动保存；返回首页、打开其他草稿和关闭窗口前立即保存。保存失败显示原因，可重试；关闭时可选择继续编辑。
- 首页最近工作可继续编辑或复制为新草稿。旧草稿不会因为程序升级或换资料库而重建。
- 右上「设置与备份」可导出全部草稿与项目备份，并从备份恢复。恢复创建新副本，不覆盖本机草稿。
- 数据目录沿用 `%APPDATA%/dss-desktop-workbench/data`。可在设置里打开；升级、回退和卸载都保留这些数据。
- 每份草稿保留上一次成功保存的版本；正文文件损坏时尝试恢复，并显示提示。备份文件仍是跨电脑恢复的可靠入口。

## 升级、回退与卸载

先保存并关闭客户端，用新包中的 `DesktopSetup.exe` 安装升级。升级保留旧程序目录，其位置记录在安装目录的 `PREVIOUS_VERSION.txt`；不要手工修改或删除该文件。

需要回退时，先备份草稿并关闭客户端，打开安装目录中的 `DesktopRollback.exe`，按提示回退上一版本。旧版不认识的新字段可能无法继续编辑，请保留本版导出的备份与 DOCX。

卸载使用 Windows「已安装的应用」中的「EngiSpace · 设计说明」，或双击安装目录的 `DesktopSetup.exe`。卸载保留草稿、项目、配置和已导出的文件。

## 集中试用

重点查看：少填参数仍能导出；参数区域不重复；原有草稿可恢复；正文和表格可编辑；长章节可滚到底；关闭重开保留最后修改；安装、升级与卸载入口可用。字体、缩放、Word/WPS 分页与专业正确性尚待人工验收。

发现问题时提供模板名、章节/参数位置、操作步骤及实际现象；已有源文件不需要上传到公开仓库。本包未正式发布，不能把必要开发检查当作人工验收通过。
