# T12 专业签收单（结构专业）

本单由结构专业设计人员在完成屏幕核对（`T12_ACCEPTANCE.md`）与打印核对（`T12_PRINT.md`）后填写。签收只针对图面与版式是否符合院标预期，不替代性能与安装验收。

## 签收范围

- 说明文档：结构设计说明（构筑物）验收样本（本地测试包内 sample.docx 及后续不同 DOCX 样本）。
- 图幅与模板：A1 三栏 / A2 三栏 / A3 两栏，随包默认模板 jsr-note 1.0.0。
- 检查对象：真实 AutoCAD 2021 模型空间生成的 DBText 图面（屏幕 + 打印各一次）。

## 核对项

| 项 | 预期 | 结果（通过/不通过/不适用） | 备注 |
| --- | --- | --- | --- |
| 标题层级 | 标题 1/标题 2 与正文层级、字高符合院标 |  |  |
| 分栏 | A1/A2 三栏、A3 两栏，栏宽一致 |  |  |
| 续页 | 跨栏、跨页接续正确，无空白尾页 |  |  |
| 行距与段落 | 行距均匀，段间距一致，无重叠 |  |  |
| 编号 | 条目编号连续、不错行、不重复 |  |  |
