# AutoCAD 2021 测试入口

先退出正在打开的 AutoCAD，再重新打开。当前这次 AutoCAD 如果已经 NETLOAD 过旧 DLL，新命令不会出现。

1. 打开一张空白图。不要用「新块.dwg」。
2. 命令行输入 NETLOAD，回车。
3. 选择这个文件（同目录下的其他 DLL 要留在一起）：
   `artifacts/dn-note/Justified.SpecificationReflow.AutoCAD.PluginHost.dll`
4. 出现安全提示时，确认是本项目文件后再加载。不要关闭 SECURELOAD，也不要改信任路径。
5. 输入 DN_DIAG，回车。出现 DN_DIAG_OK 表示依赖加载通过。
6. 输入 DN_NOTE，回车，然后按提示：
   - 选择「测试文件/示例-单行说明.docx」。不要选「示例-结构说明.docx」，那份含有尚未标定的上下标，命令会拒绝整篇并且不写图。
   - 标准目录填：`G:\JUSTIFIED_specification reflow for AutoCAD\standards\drafts`
   - 图幅输入 A1（直接回车也是 A1）。A2、A3 也可以。
   - 单位比例输入 `1`。这表示 1 个标准毫米等于 1 个图形单位。不要留空，程序不会猜。
   - 在图上点一下，作为说明区右上角。
7. 把命令行从 DN_NOTE 开始到结束的全文发回。

单位比例为 1、点在原点附近时，第一行应接近：x = 点的世界坐标 X - 710，y = 点的世界坐标 Y - 6.2，字高 4.5，宽度系数 0.75。特性面板里对象类型是单行文字（DBText），样式名以 jsr-note-1.0.0- 开头。

再执行一次 DN_NOTE，不删除旧字。图上应有两套文字。输入一次 U，只去掉第二次写入的那一套。

草案提示 DN_NOTE_DRAFT 是预期现象，不代表院标已经发布。字体必须能被 AutoCAD 找到（tssdeng.shx、tssdchn.shx）；找不到时会失败，并且前后实体数相同。

旁边的 ZIP 仍是较早的诊断包。这次请用上面的 artifacts/dn-note，不要用正在被 AutoCAD 锁住的旧 bin 目录。
