# AutoCAD 2021 测试入口

测试文件就在开发目录的「测试文件」文件夹里，不用再找 AppData。

1. 如果之前加载过本插件，先退出并重新打开 AutoCAD 2021，以免继续使用旧 DLL。
2. 打开一张空白图，在命令行输入 NETLOAD，回车。
3. 在文件选择窗口进入本文件旁边的「程序」文件夹，选择：
   Justified.SpecificationReflow.AutoCAD.PluginHost.dll
4. 如出现安全提示，确认是本项目文件后选择加载；无需关闭安全设置。
5. 输入 DN_DIAG，回车。出现 DN_DIAG_OK 表示本次依赖加载检查通过。
6. 如有报错，把命令行内容发回当前对话。

不要双击 DLL，也不要只把一个 DLL 单独搬走；「程序」内其他 DLL 是配套依赖。
这只是加载诊断，不生成设计说明，不修改图纸。

旁边的 ZIP 是完整离线包，可复制到其他电脑；解压后按包内 INSTALL.md 操作。
以后执行 Package 构建，会同步更新这里的「程序」和 ZIP。若提示文件正在使用，先关闭 CAD 后再构建。
