# DOCX 输入说明（V1 解析基线）

本说明描述解析器当前接受的 DOCX，不是院标标定结果。Word/WPS 的真实同内容样本仍待 CAL-06，合成包不能代替那一步验收。

可打开的脱敏样本在仓库的「测试文件/示例-结构说明.docx」。它使用 Word 内置样式 Heading 1、Heading 2、Normal，并带有十进制自动编号、空行、硬换行、上下标和字面 ²。页眉页脚不进入正文。

调用方必须同时给出三样东西：DOCX 字节、样式映射、documentId 与 disciplineCode。解析器不会把未列出的样式猜成正文，也不会把缺省专业写成 structure。

映射可以按 styleId 或样式显示名匹配，英文名称忽略大小写。一级、二级标题允许沿 basedOn 继承。正文必须写在映射里；基于正文的其他样式（包括三级标题）不会自动变成正文。

支持：

- 已映射的一级标题、二级标题、正文，按阅读顺序输出。
- 手工编号留在原文字里，不再自动加一遍。
- 十进制单级、多级自动编号，以及 startOverride、新列表和 lvlRestart=0 的重启。编号放在独立 label 中，不写进正文。
- 真正的空段保留为一个空槽；连续空段不合并。文档最后那一个空段视为编辑器终止段，不输出。
- 显式换行保留为独立的换行 run。只起分页作用的分页符、分栏符、分节符不进入正文。
- 上下标保留语义。字面 ²、³ 保持原字符。
- 页眉、页脚不进入正文。宏不执行。

会阻断并给出段落位置：

- 表格、图片、文本框、公式、脚注、尾注、批注、嵌入对象、拼音指南、符号字体。
- 未接受的修订、未转成静态文本的域。
- 制表符。不要用 Tab 表示缩进。
- 未映射样式，以及 bullet、罗马数字等非十进制编号。
- 损坏、加密或无法打开的文件。

加粗、斜体、下划线、颜色、字体和字号只产生“已忽略”的提示，不改变块类型和文字。页边距、段前段后和行距不读取。资源上限未标定；只有调用方传入时才检查文件大小。
